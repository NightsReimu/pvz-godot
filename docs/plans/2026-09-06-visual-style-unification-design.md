# Battle Visual Style Unification Design

## Goal

把普通植物、普通僵尸、投射物和战斗特效统一到火山扩展新单位使用的 procedural 视觉语言，同时保留旧单位和东方 Boss 的识别造型。

## Chosen Direction

采用“统一渲染外壳 + 世界主题色”的方案。单位本体继续使用已有 procedural 绘制或 image2 资源；共享绘制入口负责补充底部阴影、深色描边、高光、受击闪白、减速/魅惑/护盾等状态反馈。投射物和命中特效使用统一的核心、外圈、轨迹和落点结构。

## Visual Rules

- 单位落点有稳定的椭圆阴影，阴影透明度随跳跃和悬浮状态降低。
- 资源绘制保留原始尺寸，但统一最小可见轮廓和高光层，避免大小差异造成战场层级混乱。
- 植物使用深青色轮廓，僵尸使用深灰绿轮廓；世界主题只改变高光和状态色。
- 受击闪白、减速冰蓝、魅惑紫、护盾青色使用同一套叠加规则。
- 投射物至少包含柔和外圈、实心核心、左上高光和短轨迹；高威力投射物增加环形脉冲。
- 特效遵循“核心 + 外圈 + 轨迹 + 状态颜色”，并保持有限线宽和稳定半径。
- 东方 Boss 的符卡图像和专属符号继续保留，只添加统一轮廓、落点、预警和受击层。

## Scope

- `scripts/game.gd`：植物、僵尸、投射物、卡片图标和特效的共享绘制辅助函数及调用点。
- `scripts/runtime/volcano_expansion_runtime.gd`：抽取与主战场一致的轮廓、阴影和状态色规范，确保火山单位继续作为风格基准。
- 视觉回归截图：桌面和移动横屏各覆盖普通单位、火山单位、Boss 和特效。

## Non-goals

- 不重写每个植物或僵尸的战斗逻辑。
- 不替换已有 image2 资源。
- 不改变东方 Boss 符卡的伤害、时停或召唤机制。

## Acceptance Criteria

1. 普通和火山单位在战场、卡片和图鉴中拥有一致的轮廓、阴影和状态反馈。
2. 旧资源、procedural 单位和东方 Boss 都能在同一渲染入口正常绘制。
3. 投射物和命中特效在移动和桌面分辨率下不产生尺寸跳变或遮挡生命条。
4. Godot 解析、既有测试和新增视觉快照检查通过。
