# v1.0.162：融合行为与弹药修复

用户授权：大改融合，保留材料的攻击方式、选敌、被动与对空能力，修复移动目标落点，扩充组合弹药和魔术花弹池，排除花盆/莲叶，大招回满血，验证并发布。

根因：融合以通用攻击分类替换原植物逻辑；投射物保存静止落点；融合落地处理提前返回，绕过原弹药的特殊命中；大招融合分支早于共用治疗。

实施：
1. 增加移动目标、跨行月炉、莲矛环射、提灯对空、火焰玉米/黄油、禁用底座及治疗回归。
2. 提取原生行为调度供原植物/融合材料共同调用。每种材料独立保存计时、蓄力、成熟、曝光等状态。灰烬类仍用独立长冷却爆发，不把秒杀伤害注入普通弹。
3. 投射物绑定目标 UID，落点随合法目标更新；目标消失/魅惑后保留最后合法落点。月炉维持全场选敌并跟踪。
4. 保留原弹药种类和特殊命中，组合元素用独立载荷与外观层；扩充魔术花弹药目录，包括新组合弹。
5. 核对全植物调度和场外被动查询；底座退出所有融合入口；融合大招也先治疗。
6. 实战/全量回归、视觉检查、四平台 release 与 Pages 部署验证。

本地验证完成：144/144 回归入口通过（火炬穿越测试的初始步长未实际越过触发范围，修正测试步长后单项复跑通过）；原生渲染截图、32 弹体/载荷展示三帧、桌面/移动战场均通过。待发布四平台与 Pages 验证。
