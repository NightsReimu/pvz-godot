# 古代庭院、天气与小游戏融合改进

**Goal:** 完成第八世界背景优化、四种新天气、跨植物/僵尸天气效果、小游戏融合修复、组合弹药和大招改进，并发布 v1.0.164。

**Architecture:** 延用程序绘制与 SVG 资源。天气继续由 AncientExpansionRuntime 管理，按关卡 weather_schedule 启用，统一识别原种、融合材料和弹丸载荷。小游戏保留自己的种植/胜利规则，只在兼容普通棋盘的模式开放融合。

**Tech Stack:** Godot 4.6、GDScript、现有 SceneTree 回归测试、GitHub Actions 多平台导出。

1. 先补行为回归并运行红灯：落种叠种/场上融合、传送门核心保护、融合星位与照明、外世界天气、元素子弹、新天气、组合弹药、大招齐射。
2. 修复融合入口与小游戏组件识别，整列模式沿用一张卡覆盖所有合法行，避免绕过核心保护与免费复制种子。
3. 增加飘雪、冰雹、沙尘、虹光。按天气修正普通敌人速度、原种/融合火冰雷载荷与充能；天气随重开复位，暂停不推进。
4. 增加茶蚀/奶浪载荷，补全古代雷电材料；分裂弹保持载荷；重绘拖尾和反馈。融合攻击大招采用三个间隔齐射，继承原生大招并限制重复爆舱。
5. 重画庭院景物和石径，天气渐变、云层、积雪、尘雾与虹光分层，桌面与手机尺寸原生截图检查。
6. 运行相关和完整测试、headless 导入及 Web 导出，更新版本与发布说明。提交、推送 v1.0.164 tag，等待 Windows/macOS/Web/Android 发布及 Pages 完成，核验四个附件。

与大规模替换背景图片相比，沿用程序背景能保持不同屏幕上的棋盘布局；与直接给全部小游戏开放所有操作相比，按规则保护三消与核心能避免破坏目标。

验证结果：133个Godot回归脚本与14个Python回归脚本完成；旧整列断言及融合审计排除名单更新后，相关9个脚本复测通过。天气回归额外覆盖大步长轮换、跨关卡清理、火山弹丸、直接火焰、两种雷电链、融合载荷、奶浪击退间隔和大招后续攻击。原生截图覆盖十种天气、1600×900与844×390、七个小游戏，修正了手机天气条遮挡按钮。Godot 4.6 headless编辑器导入、最终Web导出及文档/发布配置检查成功。现有测试的退出清理告警仍会出现在部分脚本中，已检查无行为断言失败或GDScript异常。
