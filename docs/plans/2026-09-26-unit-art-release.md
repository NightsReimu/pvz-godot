# v1.0.138 全量单位复查与美术优化

用户要求独立审视最近几轮 Release，不能把之前的绘画方案视为必须沿用的设计。

已逐页查看 146 种植物、129 种僵尸的实机图集（含 29 组东方角色原始图片）。主要问题：植物几何形状过于简单、圆形叶片、材质不明确；抽卡植物前景光线遮挡面部；普通僵尸四肢过细、身体矩形化；部分特殊僵尸五官和装备缺乏层次。

实施：
- 重新绘制植物的曲线 SVG 造型，以具体物种和玩法为依据保留辨识度，适配卡片、图鉴、预览和战场。
- 坚果裂纹、幼年阳光菇、胆小菇躲藏、土豆雷布雷、食人花咀嚼等状态不得丢失；保留现有动作变换。
- 重绘共享僵尸身体，改进特殊僵尸的五官和装备；东方角色保留用户提供的角色图。
- 修复最近魔术花子弹分支重复、串改其他子弹、部分随机弹不吃伤害倍率等问题。
- 用桌面和手机尺寸图集、状态像素对比、全量回归以及四平台 Release 构建验证。
- 当前未提交的 3-25 EX 关卡一起纳入新版本。

验收与实际覆盖统计在发布说明中据实记录，不把“全量检查”表述为“每张图片重画”。

## 完成记录

- 144 个植物物种、166 份 SVG（含状态），缓存由 VectorUnitArt 统一调用。火炬原生动画和保龄坚果派生覆盖余下两种。
- 新共享僵尸身体/五官覆盖常规敌人及各自装备，特殊角色保留外形并补齐面部；纠正蟹腿、蟹钳与熔岩裂纹重复加坐标。
- 魔术花与方形范围回归先复现失败，再修正至通过。永琳/辉夜原有高难度扩展区分为追击、交叉与阵地弹幕。
- 122 个测试入口通过：112 个 headless GDScript、2 个原生渲染 GDScript、8 个 Python。雾 Boss 原测试要求随机额外行必定出现，改为 32 个种子检验实际保证的四层效果；同角色道中计时测试隔离了场景时钟伤害。
- 全图集和四尺寸战场检查见 output/unit-identity/release-138；3-25 两尺寸两难度截图见 output/mokou；各测试日志见 output/release-138-validation。README 保存一张原生实战预览。
- 发布版本 v1.0.138，项目与 Windows/macOS/Android 元数据同步。四平台构建由既有 Release 工作流执行。
