# 东方高难原创招式与 4A/B 强度

用户要求所有东方 Boss 随难度增加招式，允许原作之外的新技能；补充反馈灵梦与魔理沙相对其他 Boss 仍偏弱。

## 实现

- 移除 4A/B 的追加阶段例外。Normal / Hard / Lunatic 累计追加 1 / 2 / 3 招，EX+ 追加两招，23 位 Boss 及五种道中路线共用规则。高档保留前档原创，原作变体和终符顺序保持。
- 给每个原创追加阶段独立名称、编号与弹型。保留角色追击，再加入双侧夹击和延迟围阵；冻结、折向、反弹、曲线、激光与可见人偶发射点按角色主题组合。显式标注原创，难度菜单显示新增数量，攻击段和独立招式不混称。
- 灵梦三招配合追踪御札、阴阳夹击、轮换空列符阵及不同封印/保护格；魔理沙配合反弹星弹、旋转交叉光束、轨道星环/三束扫射及不同蘑菇/光符布局。保留至少一秒预警、六格上限、阶段清理与反制入口。
- 4A/B 生命 28,500 / 29,200，单弹伤害系数 1.45 / 1.35，激光 1.35 / 1.22，后段伤害每档 +12%、最多三档。弹速 +12% / +10%，密度 +16% / +15%，发射间隔 -10%；技能/援军间隔分别以 5.5 / 5 秒起算。角色和难度系数集中计算一次，其他角色数值保持。
- 截图工具按实际阶段索引拍摄，覆盖新增招式，并像正常游戏一样清理已死亡的蘑菇。

## 验证

- 先用严格递增的阶段、不同弹型数量、原创继承和原终符顺序检查复现旧问题，再修改实现。
- 34 项 Godot 战斗、机制、难度、地图、动画与 UI 回归通过。新增测试不只比较名称和数值，还比较相同难度/战斗强度下的发射位置、轨迹、延迟运动及人偶光束实际起点。
- 4A/B 全部四档必需攻击顺序通过爆发伤害门控，最终分别为 5/7/8/9 阶段及 10/12/13/14 次必需攻击。
- 桌面与 844×390 手机原生截图覆盖原作与新增阶段；难度菜单另检查 568×320 小屏。
- 原作符卡静态碰撞测量工具为 `scripts/tools/measure_touhou_damage.gd`，分别以 v1.0.103 资源包与当前源码运行相同外部脚本；数据保存在 `docs/benchmarks/touhou-4ab-v1.0.104.json`。此测量不代表整局 DPS 或通关率。
- Web 资源包导出成功；包内新增招式测试与灵梦/魔理沙四档种植、音乐、暂停、阶段、重开、援军和胜利流程全部通过。最终符卡契约复验通过。
- Android 导出配置与发布工作流 Python 检查通过。README 质量检查仍仅报告既有根目录 `RELEASE_NOTES_v1.0.93.md`，未改动该历史文件。
- 按既有授权发布 v1.0.104 四平台构建。
