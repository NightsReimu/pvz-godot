# 3-24-b 蓬莱山辉夜设计与实施计划

**Goal:** 沿用 3-24-a 永琳道中，新增辉夜终末、五道难题与永夜归返，并修正东方敌人池。

**Architecture:** 6B 从 6A 的关卡数据深复制，仅覆盖分支标识、地图节点、终末事件与音乐。共用回廊退出、临时世界格及全世界增援；辉夜独立运行时持有宝物、定点攻击与一次性战斗快照。复用既有东方阶段、难度、弹幕上限和资源尺寸校准。

**Tech Stack:** Godot 4.6 / GDScript，Pillow / OpenCV 素材裁剪，原生 SubViewport 截图。

用户已明确要求实现以下设计，直接执行。整体复刻世界存档会牵连奖励与进度；只做视觉倒转则不能满足复活要求。因此采用有预告、有限时长、仅作用于植物及普通僵尸的战斗快照。

## 战斗规则

- 东方关卡所有出场路径把 mech_zombie、flywheel_zombie 替换成已有合理强度单位；其他世界保持原有内容。
- 3-23 在固定事件及道中/终末增援加入飞艇玉兔，沿用两艘上限与往返投兵机制。
- 3-24-b 与 3-24-a 共享全部道中事件、传送带、永琳 12% 血量道中和音乐。按用户要求保留 A 道中符卡；原作 6B 实际为 No.148–151「壶中的大银河」，明确记录这项定制差异。
- 辉夜五道难题依次为龙颈玉、佛石钵、火鼠衣、燕子安贝、蓬莱枝，使用原作各难度 No.152–171。其后完整保留五段永夜归返 No.172–191，作为限时生存符卡。
- 塔防特化：五色定点打击；可击破石钵保护邻近小怪；火衣预警灼地；生命宝物持续恢复小怪并记录/回溯战场；玉枝切换世界并连锁开花。攻击均有预警，宝物随所属阶段结束清除。
- 难度追加原创永恒领域、须臾连击、蓬莱时庭，放在五道难题之后、永夜归返之前，Easy/Normal/Hard/Lunatic 为 10/11/12/13 阶段。Lunatic 自选植物。
- 回溯显示倒计时并记录当前植物（含底座）与普通小怪。倒计时结束恢复记录时的生死、位置、生命与移动状态，之后新增单位消失；Boss、符卡、关卡进度、音乐、货币、拾取物、冷却、升级和奖励结算不回退。回溯范围内所有小怪每 UID 只结算一次死亡；复活植物不能重复获得大招能量；分裂和投兵随实体状态恢复且受总量限制。
- 短时失去植物可能较严厉，用预警让玩家能决定何时补种；清除射弹避免旧命中引用误伤。暂停冻结倒计时，阶段结束/击败/重试取消待回溯。
- 使用用户提供的 24 格辉夜原图，按统一尺度裁剪去底，保留黑长发、服装及五宝；不触碰旧 Boss 图片。

## 实施与验证

1. `scripts/data/kaguya_level_defs.gd`、`kaguya_spell_defs.gd`：数据、原作编号与难度路线；接入 `level_defs_pool.gd`、`touhou_spell_defs.gd`、`touhou_difficulty_defs.gd`。
2. `scripts/runtime/kaguya_boss_runtime.gd`、`kaguya_danmaku.gd`、`kaguya_visuals.gd`：非射击技能、回溯、五宝绘制与终末背景；接入 `game.gd` 和共享 Eirin / Touhou runtime。
3. `scripts/tools/prepare_kaguya_frames.py`、`art/kaguya`、`audio/th08_kaguya_boss.mp3`：裁剪透明图、来源摘要、动画、BGM。
4. `tests/kaguya_level_test.gd`、`kaguya_mechanics_test.gd`、`kaguya_battle_flow_test.gd`：真实生死回溯、唯一奖励、底座、宝物破解、伤害预警、两尺寸及四难度完整流程。
5. 运行 `godot --headless --path . --script tests/<test>.gd`；原生 `--capture` 检查素材、倒计时、场景和 UI。回归 Eirin/Reisen、东方难度/符卡、传送带/治愈葫芦/世界导航。
6. 更新版本、发布说明，使用 NightsReimu 的 author/committer 提交推送，检查 GitHub 四平台 release 构建结果。
