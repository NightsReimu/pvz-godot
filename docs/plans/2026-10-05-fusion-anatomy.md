# 融合解剖：把融合画成一株新植物

## 问题

v1.0.163 的融合由“最结实的本体 + 其余材料的标志部件”组成。部件保留原色，并装在固定位置，豌豆融合因此总是在侧面多一根绿色炮管，樱桃融合则在头上多两颗樱桃，结果容易猜到，看起来也像套模板。灰烬材料融合后，爆舱和大招会把气球当作“车道攻击看不见的目标”跳过，失去了原种的对空能力。

## 设计

每种基础植物拆成可组合的“基因”：

| 基因 | 来源 | 作用 |
| --- | --- | --- |
| 体型 `form` | `fusion_traits.py` | 武器、作物和树干轮廓优先成为身体；普通豌豆让位给更结实的身体，特殊射手保持射手体型 |
| 材质 `mat` / `MATERIAL` | 同上 | 搭档材质明显更醒目时，为整株换皮（浅→深色轴映射，高光与暗部随之变化） |
| 纹理 `pattern` | 同上，`fusion_patterns.gd` 绘制 | 以遮罩铺在皮肤上，避开眼睛、嘴和炮口 |
| 饰物 `acc` | `fusion_accessories.py` | 头冠、光环、头盔、尾巴、底座等与身体相连的部件 |
| 武器 `weapon` / `muzzle` | 同上 | 无武器的身体从嘴部长出搭档炮管；已有炮口的身体改装炮口 |
| 表情 `mood` | `fusion_traits.py`，`fusion_flair.gd` 绘制 | 怒眉、霜眉、睡眼、螺旋眼、电光眼等 |
| 元素 `elems` | 同上 | 头旁徽记、叶色和战场循环特效 |

`fusion_anatomy.py` 渲染标记色来测量每株植物的皮肤区域、眼睛、嘴和炮口，并把皮肤颜色模板化为 `{sN}`。底座和叶片用 `data-part="base"` 标出，不会被换色。组合器 `fusion_plant_morphology.gd` 按体型、材质、纹理、武器、饰物、表情与元素的顺序生成 SVG；固定 SVG 和运行时递归融合使用同一套代码。

## 对空

`fusion_combat_profiles.gd` 的 `ASH` 列出原种能炸到空中的灰烬材料。融合爆舱、投掷爆弹以及爆破、炎阵、汽爆大招判断隐藏目标时，只对这些材料放行气球，挖地、潜水等其他隐藏状态不变。地雷、窝瓜、海草与大嘴花仍只打地面。

## 验证

- `tests/fusion_anatomy_test.gd`：灰烬融合能击伤气球（关闭修复后该测试失败），地雷融合不能；樱桃射手保持射手体型并换成红色，有纹理和表情；坚果从嘴部长出喷口；寒冰射手与大嘴花融合时只改装炮口；不同搭档给出明显不同的皮肤。
- `tests/plant_fusion_art_test.py`：11,219 个 SVG 几何签名唯一。
- `tests/fusion_model_identity_test.gd`、`tests/universal_fusion_art_test.gd`：可渲染性与轮廓差异。
