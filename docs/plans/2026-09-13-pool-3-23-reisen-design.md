# 泳池世界 3-23 永夜抄五面设计

**日期：** 2026-09-13

## 目标

新增泳池世界 3-23，复现《东方永夜抄》五面“永远亭/无限回廊”的关卡气质：因幡帝作为道中 Boss，铃仙作为终末 Boss，使用用户提供的音乐与 24 格角色参考素材，并加入与植物大战僵尸玩法兼容的月兔、月食、狂气之瞳和回廊折返机制。

## 设计决定

- 场地使用六行纯草地，不保留泳池水格。战场坐标保持稳定，只有背景回廊旋转，避免影响操作和碰撞。
- 3-23 使用 `3-23道中.mp3` 作为关卡音乐，`3-23终末.mp3` 只在真正终末 Boss 入场时播放。
- 因幡帝和铃仙都使用各自的 24 帧 PNG；素材从用户提供的 6×4 图集中裁剪并保持原始画风、动作顺序和透明背景。
- 因幡帝是铃仙前的同角色道中预览：只有一段开场非符，血量为终末同难度总生命的 12%，必须被玩家击破。道中期间继续生成普通和主题小怪，但事件批次、波数和进度条冻结；击破后恢复队列并保留存活小怪。
- Easy 保留永夜抄五面核心符卡。Normal、Hard、Lunatic 按现有东方难度系统逐档追加原创符卡和阶段压力；最高难度可继续使用自选植物模式。
- 铃仙的终末强度来自完整阶段路线、狂气状态、月食场地控制、召唤传送门和高难度原创符卡，伤害仍通过现有东方伤害倍率控制。

## Boss 机制

### 因幡帝道中

- 仅循环帝的开场非符，使用低强度兔形弹幕。
- 定时刷新少量月兔主题小怪，不调用终末技能，不切终末 BGM。
- “幸运兔脚”给一只小怪短暂闪避，帝被击破后清理该状态。

### 铃仙终末

- 原作符卡路线接入 `touhou_spell_defs.gd`，阶段顺序与现有 `TouhouPhaseRuntime` 一致。
- 狂气之瞳：绘制红色同心瞳环和扫描线；命中植物后施加短时瞄准扰乱、攻击方向偏转和冷却延长。高难度增加瞳环层数与安全区变化。
- 月食：渐进压暗回廊，降低植物射程和阳光产出；结束时产生低伤月光冲击。场地恢复和清理必须覆盖暂停、重开、阶段切换和 Boss 死亡。
- 月兔传送门：空格出现可攻击的倒计时门户，开启后生成月兔僵尸；门户在 Boss 清除、阶段切换和重开时清理。
- 无限回廊折返：部分弹幕经过右边界后从左侧预警折返，视觉路径不改变植物/僵尸的实际碰撞坐标。

## 资源与配置

- 新增 `scripts/data/level_defs_pool.gd` 的 3-23 配置，接续 3-22-a 与 3-22-b，六行纯草地，必带 `healing_gourd`，传送带替换为月夜和回廊主题植物。
- 新增一组 3-23 主题僵尸事件，至少包含月兔、传送门生成物、狂气强化小怪和少量泳池世界兼容单位。
- 新增 `art/tewi/frame_00.png`–`frame_23.png` 与 `art/reisen/frame_00.png`–`frame_23.png`，按现有 Boss 帧加载、预热、绘制和测试约定接入。
- 新增 `audio/th08_tewi_stage.mp3` 与 `audio/th08_reisen_boss.mp3` 的项目资源副本，来源分别为用户提供的 `3-23道中.mp3` 和 `3-23终末.mp3`。
- 主题背景增加 `infinite_moon_corridor` 绘制分支，包含旋转环廊、月轮、透视线和低亮度月光。

## 验收标准

- 3-23 能在地图中解锁、打开四档东方难度，并在 Lunatic 进入自选植物。
- 道中帝出现时不切终末 BGM；道中小怪继续出现；波数、事件队列和进度条不动。
- 帝必须被击败后才能继续终末事件；道中生命明显低于终末，并且不因计时或技能自动消失。
- 铃仙只有在帝被击破后出现，终末 BGM 在此时切换；终末完整技能路线和难度追加保持。
- 狂气之瞳、月食、传送门、回廊折返均能在暂停、阶段切换、重开和死亡路径清理。
- 桌面和窄屏横屏布局无 UI 重叠；24 帧素材全部可加载并在战斗中显示。
- 新增测试覆盖配置、资源、四档难度、Boss 门控、援军与冻结波次、机制状态、BGM 和实际帧循环。
