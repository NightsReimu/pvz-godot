# Smooth Preparation And Planting Animation Design

## Goal

让选卡和战斗种植流程拥有接近原版《植物大战僵尸》的连续动效，同时保持现有玩法、输入区域、移动端布局和东方 Boss 资源不变。

## Approved Design

选卡界面继续使用现有植物卡池和卡槽点击逻辑。桌面布局保留植物卡槽、植物池和操作按钮，并把僵尸预览绘制升级为真实僵尸图标队列。进入选卡时，每个僵尸图标从预览区左侧错峰滑入目标位置，带轻微透明度和缩放变化；移动端继续使用当前纵向面板，图标按可用宽度压缩，避免覆盖点击区域。

植物卡加入卡槽时记录一次短暂的飞入动画，从卡池卡片位置移动到对应卡槽，落位时使用轻微回弹和高光。移除卡槽植物时使用短暂缩小淡出。动画只影响绘制，选择数组仍在点击时立即更新，因此键鼠和触摸操作不会被动画阻塞。

战斗中选择植物后，植物预览平滑跟随指针，并在最近的可用格子上显示吸附位置、透明度和有效性颜色。成功种下时复用现有植物的 `spawn_time` 绘制入口，增加一次落地阴影和短促光晕；无效格子保持红色提示，不创建额外运行时单位。动画时间固定且轻量，避免在大量弹幕时创建高频粒子。

## State And Data Flow

在 `scripts/game.gd` 增加仅用于 UI 绘制的计时和目标状态：选卡场景进入时间、僵尸队列目标进度、卡槽飞入/退出记录，以及战斗中平滑的悬停位置和最近落位提示。`_process` 每帧更新这些值并在选卡或战斗状态下请求重绘；点击函数继续负责真实状态变化。

动画绘制通过现有 `_draw_card_icon`、`_draw_zombie_icon`、`_draw_plant_preview` 和 `_draw_plant_body` 接口完成，不修改东方 Boss 的资源文件或其战斗逻辑。位置计算复用 `_selection_*_rect`、`_selection_slot_rect` 和 `_cell_center`，确保布局测试仍以同一组点击矩形为准。

## Validation

新增一个轻量 GDScript 测试，验证选卡进入会初始化动画状态、僵尸预览队列按目标位置推进、卡槽动画记录不改变 `selection_cards`，以及战斗悬停位置会收敛到鼠标目标。运行该测试、`tests/game_boot_test.gd`、相关布局测试和 `git diff --check`；再使用 Godot 的非 headless 捕获工具做桌面与窄屏视觉检查。
