# 3-23 实战压力调整设计

**日期：** 2026-09-13

## 目标

解决 3-23 实战中植物几乎不掉血、铃仙技能偏向干扰而缺少有效伤害、道中与终盘小怪池过窄的问题。保留铃仙与因幡帝的生命值、原作符卡顺序、狂气之瞳的幻视表现、月门数量上限和治愈葫芦的回血职责。

## 方案

- 统一提高东方符卡的实际伤害系数：Easy / Normal / Hard / Lunatic 从 0.40 / 0.47 / 0.56 / 0.67 提高到 0.50 / 0.60 / 0.72 / 0.86，EX / EX+ 提高到 0.50 / 0.82。通用弹体基础伤害从 22 提高到 32，阶段成长从 4 提高到 6；不增加 Boss 生命。
- 铃仙独立提高普通弹、光束、后段成长、弹速、密度和施法频率。狂气之瞳标记植物每 1.45 秒受到一次真实伤害，同时保留攻速干扰和友方弹道偏转。
- 3-23 的普通事件与 Boss 援军按前、中、后三段混入已有的挖掘、气球、足球、铁门、忍者、暗影、巫师、暗黑足球和巨人僵尸，月兔斥候/卫兵继续承担主题敌人职责。
- 治愈葫芦只走已有回血逻辑。它可以被狂气之瞳标记、受到月食影响、被月光冲击伤害，不提供 3×3 保护、免疫或减伤。

## 验收

- 3-23 事件表至少包含 10 种敌人，并包含挖掘、气球、足球、巫师和巨人。
- Hard 铃仙弹体伤害达到新的伤害下限，狂气之瞳会实际扣除未被无敌保护植物的生命。
- 治愈葫芦在眼格、月食阳光减速、射程限制和月光冲击中与普通植物一致，只继续执行回血。
- 3-23 道中门控、BGM、暂停、重开、弹幕碰撞和 480 弹上限回归通过。
