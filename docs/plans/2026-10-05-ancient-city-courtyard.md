# 东方古城庭院与青石棋盘 Implementation Plan

**Goal:** 将第八世界改成用户选定的东方古城庭院，建筑在实战中可见，种植格从草坪改为青石种植台，并发布新版。

**Architecture:** 专用背景插画负责古城建筑、院墙和石阶，按顶部、两侧和底部切片适配棋盘。AncientVisuals 独立绘制青石台、雕纹和接缝；种植与战斗仍使用同一套逻辑坐标，天气覆盖保留。第八世界单独预留顶部建筑空间，其余世界维持原布局。

**Tech Stack:** Godot 4.6、GDScript、imagegen 专用背景、缓存 Texture2D、原生截图和现有 SceneTree 回归。

1. 制作一张横向东方古城庭院背景：青灰瓦殿、红柱、宫墙、石阶与铜灯，中央保留低对比度的空院落，避免人物或植物。
2. 为 ancient 关卡增加独立棋盘绘制入口，按真实45格绘制倒角青石台、铜色角饰、裂纹、嵌刻云纹和接缝苔痕；删除草坪叠加及通用白线格子。
3. 拆分背景顶部、左右和底部的绘制区域，对齐棋盘边界，并预留上方建筑带；缓存贴图，天气色调、雨滴水纹和积雪继续渐变。
4. 检查1600×900、1365×768及844×390的晴天、雨雪截图，修正建筑遮挡、格子过密、天气条与操作区域的重叠。
5. 验证种植格点选坐标、其他世界布局、天气及第八世界战斗和启动；更新文档与版本，沿用四平台发布工作流发布并核验附件。

验证以运行时几何、真实种植和原生截图为主，不为可逆装饰细节编写逐条实现断言。

实施完成：专用 PNG、三种石台 SVG、古城卡片透明边缘、主页与旅行手册封面、选卡预览均已接入。布局回归先复现原先建筑空间不足，再验证修复后的45格坐标和种植保留。16项相关 Godot 回归与3项 Python 文档/发布配置检查通过；10张原生截图覆盖三种窗口尺寸、晴雨雪、世界选择、选卡和背景预览。最终 Godot 导入及 git diff --check 通过。
