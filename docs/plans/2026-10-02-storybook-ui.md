# 幻想庭院界面 Implementation Plan

**Goal:** 将主菜单、世界选择和功能页面改造成有插画材质、统一交互反馈与真实动效的游戏界面，并发布新版。

**Architecture:** 保留现有点击区域、缩放、滚动、存档和玩法数据。新增独立的 `scripts/ui/storybook_ui.gd` 管理插画九宫格、弹性悬停、按压、粒子与页面入场；`garden_menus.gd` 重做主菜单和旅行手册。其他功能页通过公共绘制入口接入材质与动画，沿用各页面明暗色系。

**Tech Stack:** Godot 4.6 / GDScript，内置 imagegen 生成 RGBA 插画，Godot 原生截图与无界面回归。

用户已授权整体优化和发布；风格选项为可选反馈，未回复时按温暖手绘幻想乡庭院实施。

1. 检查导航与缩放约束；生成庭院、纸张、木牌、悬挂灯笼，保存原始文件与提示词。
2. 实现独立展示层：缓存图像边界，九宫格保持边角比例，有限状态动画与粒子。测试大时间步稳定性、状态清理和暂停时玩法不变化。
3. 主菜单使用插画告示板、世界邮票、植物伙伴和明确的入口层次；世界选择增加场景邮票、旅行手册、插画切换、真实进度和主题环境粒子。
4. 图鉴、小游戏、每日、基建、强化、召唤、选卡、暂停与结果窗口接入共享材质、按钮及交互反馈。
5. 运行导航、手机缩放、UI 布局、选卡、基建、召唤、更新与战斗暂停回归；截图逐页检查桌面与手机，比较动态画面。
6. 更新版本和发布说明，推送标签。确认四平台构建、公开 Release 与实际发布包资源通过验证。
