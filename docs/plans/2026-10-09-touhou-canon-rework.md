# 红魔乡 · 妖妖梦 · 永夜抄 Boss 原作符卡还原与演出美化（v1.0.185）

**目标**：风神录以外的东方 Boss（红魔乡 1-17～1-23、妖妖梦 2-25～2-31、永夜抄 3-19～3-21）按原作重做符卡的弹幕结构，并按原作补齐分难度的符卡编号与名称；统一美化子弹、激光、宣言、Boss 光环与施法动画；每张卡的伤害压力按 v1.0.184 校准，然后发布。

## 资料

- 符卡编号、名称与难度：THBWiki 的 [东方红魔乡/符卡](https://thwiki.cc/东方红魔乡/符卡)、[东方妖妖梦/符卡](https://thwiki.cc/东方妖妖梦/符卡)、[东方永夜抄/符卡](https://thwiki.cc/东方永夜抄/符卡)，2026-10-09 通过 MediaWiki API 取得。
- 弹幕结构：[东方Project攻略 Wiki](https://wikiwiki.jp/thk/) 的 紅/1～EX、妖/1～PH、永/1～3 各页的逐张说明。

## 草坪上的改编规则

- 原作中「向下飞向自机」= 本作「向左飞向植物」；原作的左右墙壁 = 草坪的上下边缘。
- Boss 站在草坪最右侧。从这里射出的全方位环，有一半一出生就飞出右边界；这几帧的子弹不再生成，弹数留给草坪上的弹幕（视觉上不变）。
- 每张卡在施法时钟上自行安排节拍（`own_clock`），不再共用 0.62 秒一波。
- 落在草坪中间生成的子弹（笼目的格子、蛰居的萤火虫、时停中布置的飞刀等）先显示为无害的出现状态，再生效。

## 平衡

每张卡的伤害压力按 v1.0.184 校准。测量：固定阵型（6×6，第 5 列坚果，其余为高生命连发豌豆），逐卡施放一次并持续到所有子弹消失，统计植物受到的总伤害；两个版本跑同样的 26 个关卡 / Boss 组合与全部难度。

- 391 个可对应的卡 / 难度组合：中位比值 1.00，278 个在 ±15% 以内，342 个在 ±25% 以内，380 个在 ±40% 以内，最低 0.54、最高 1.71。
- 新增的 H/L 符卡、莉格露和米斯蒂娅的新路线，按同一 Boss 同难度原有符卡的中位压力校准。
- 偏差较大的主要是由瞄准结构决定的卡（妖梦二百由旬之一闪、Easy 的冰符等），不同难度的结构差异使同一系数无法让四档都贴近。
- 全方位环中朝外的子弹本来就打不到植物，所以这类卡用「更密的节拍 + 适度提高单发伤害」补足；若会碰到 480 发上限，则只提高单发伤害（最多 2.6 倍）。
