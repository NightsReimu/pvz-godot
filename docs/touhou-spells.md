# 东方 Boss 符卡对照

本项目是塔防同人游戏。本轮核对以 TH06《东方红魔乡》和 TH07《东方妖妖梦》为准；不将音乐名、其他作品的招式或自创名称冒充这两作的敌机符卡。**妖梦的魂魄「怨灵使役」是 NightsReimu 明确要求保留的原创符卡。**

## 阶段流程

东方 Boss 按所选路线逐段展开，不再共用 72%、45%、20% 三个转阶段阈值。
下表统计本作的「符卡阶段」；非符是每段中的开场攻击，不单列血条。

| 路线 | Boss 与阶段数 |
| --- | --- |
| 红魔乡 Normal | 露米娅 2、琪露诺 3、红美铃 4、帕秋莉 4、咲夜 4、蕾米莉亚 5 |
| 红魔乡 Extra | 芙兰朵露 10；帕秋莉道中 3 |
| 妖妖梦 Normal | 蕾蒂 2、橙 4、爱丽丝 4、骚灵三姐妹 4、妖梦 5、幽幽子 5 + 反魂蝶终幕 1 |
| 妖妖梦 Extra / Phantasm | 蓝 10、紫 11；橙道中 2 |
| 其他道中 | 大妖精、小恶魔、莉莉各 1 段非符；六面咲夜与妖梦各 1 段；雪夜琪露诺 1 段非符 |

- 每段分配原总血量的一部分，先放角色专属非符，再展开对应的原作符卡。击破该段且必需攻击完整展开后，清除所属弹幕，短暂转场，再开放下一段。爆发伤害、大招、碾压和直接扣血不能跳过尚未展开的后段。
- 当前段未击破时，其非符与符卡继续交替；击破后等待正在展开的攻击收束。吸血、治疗不能补回已经结束的阶段。
- 妖梦第三段的剑符后穿插原创「怨灵使役」，第五段仍以「天人之五衰」收束；原创技能保留可受击怨灵与植物魅惑机制。
- 非符根据角色使用交错暗弹、冰晶扇、彩虹螺旋、五行发射点、折向飞刀、红弹交叉火力、晶星扇、雪幕、式符、人偶、三重音符、剑气米弹、蝶弹、九尾螺旋和隙间交叉弹。它们是塔防空间中的非符适配，不冒充新命名原作符卡。
- 芙兰的「之后就一个人都没有了吗？」倒计时结束即清段，再进入 QED；幽幽子五段全部击破后才进入反魂蝶；蓝退场后紫独立从第一段开始。
- 血条显示当前段血量和「当前 / 总阶段」，反魂蝶改为耐久倒计时。后期阶段继续增加攻击变化，伤害、援军、移动和素材缩放采用有上限的四档强度，不随十一段无限累乘。

## 弹幕与技能机制

- 弹幕有实际位置、方向、速度和碰撞。声明符卡不再立刻对随机格或整行扣血。激光先预警，生效期间同一株植物只受击一次。
- 完美冻结让已发出的弹幕停下，再转向释放；咲夜时停期间植物和普通弹幕停止，布置的飞刀在时间恢复后飞出。
- 四重存在由本体加三个独立出弹位置组成；折反射在棋盘上下边界反弹；「之后就一个人都没有了吗？」使用耐久窗口；QED 的环弹随时间加密。
- 爱丽丝的人偶阵与蓝、紫的式神沿连续轨迹移动，按实际位置出弹；上海人偶的预警与生效激光始终连接当前人偶位置，人偶会保留至最后一束激光结束。人偶显示现有完整人偶造型，式神与四重存在的分身采用角色动作帧。时停同时冻结出弹位置和动画。
- 妖梦「二百由旬之一闪」由半灵先发射大玉，蓄势后斩碎现存大玉生成米弹，每次斩击只转换一次，不会转换其他 Boss 的弹幕。「悟入幻想」使用底部上升米弹与正面弹流；「天人之五衰」使用不同速度的直线弹层；六面「无量劫」使用短促蓄势与周身放射米弹。
- 妖梦蓄势时自己的弹幕仍缓慢前进，樱花环提示蓄势窗口，斩后自动恢复速度；这是本作对集中感的局部表现，不赋予妖梦咲夜的全局时停能力。米弹、冰晶、飞刀、符札、星弹、音符分别使用对应轮廓，激光起点显示预警进度。
- Boss 立绘按各素材的透明边界归一到同一可见高度带，阶段成长只保留小幅增量；符卡波次会在发射前显示脉冲提示，后段提高弹速和伤害，激光保留更长的生效窗口。威胁感来自可读的蓄力、爆发和收束节奏，不通过无预警的整场秒杀制造。
- 幽幽子首次击破后进入不能用伤害跳过的反魂蝶终幕，倒计时结束后退场，不再恢复第二条血量或宣称真正复活。
- 原创怨灵接触植物后施加魅惑。正常行动、特殊连射、主动技能及能量豆入口被阻止，原射击冷却保留；魅惑结束后恢复。两层植物都正常计时，覆盖的承载植物不能透过上层植物攻击。死亡植物不再参与魅惑施放、目标选择或正常行动。
- 死亡、阶段切换、蓝到紫的交接和重新开始都会取消所属弹幕及尚未发出的波次；暂停不会推进弹幕。

## 还原边界

名称、角色归属和选定路线可以逐条核对；此实现仍不是原作逐帧复刻。棋盘为横向塔防空间，弹道、数量、射速、伤害、碰撞半径及持续时间经过适配。当前已按逐符阶段分配血量并穿插非符，但阶段分组、最低展开时间仍是本作节奏；尚未复制原作非符的独立血条、收卡奖励或所有难度和机体分支。原作后期通常有更长流程，但中 Boss、难度和机体分支会影响数量，并非每位相邻 Boss 都严格递增。

分身、人偶和式神使用实际出弹位置及角色图像，但未实现原作所有独立受击和使魔无敌规则。芙兰耐久窗口为 9 秒，反魂蝶为 24 秒，均为本作时长。蓝接紫、墓碑地形、普通僵尸援军与猩红长夜持续血线压力属于本作关卡规则，不作为原作剧情或官方符卡设定。

本次妖梦机制按上述资料区分了四张剑符；大玉切碎数量、200 像素斩弹范围、蓄势时间与人偶、式神轨迹仍为塔防适配值。「妖童饿鬼之断食」和「无为无策之冥罚」目前仍共用适配弹型，尚未完成原作独立弹道校准。

这些差异不能用「完美还原」代称。后续若做原作逐帧校准，需要按明确版本、难度和机体录制并比对逐帧弹道与阶段时序。
