# 东方 Boss 符卡对照

本项目是塔防同人游戏。本轮核对以 TH06《东方红魔乡》和 TH07《东方妖妖梦》为准；不将音乐名、其他作品的招式或自创名称冒充这两作的敌机符卡。**妖梦的魂魄「怨灵使役」是 NightsReimu 明确要求保留的原创符卡。**

## 资料

2026-09-05 通过 THBWiki 的 MediaWiki API 核对了以下列表及附带文档。符卡编号写入 `scripts/data/touhou_spell_defs.gd`，显示名、出招选择和图鉴采用同一套对应关系。

- [红魔乡符卡列表](https://thwiki.cc/东方红魔乡/符卡)：原文符名、译名、难度和机体路线。
- [红魔乡 Extra](https://thwiki.cc/东方红魔乡/Extra)：帕秋莉中 Boss 与芙兰十符的先后关系。
- [妖妖梦符卡列表](https://thwiki.cc/东方妖妖梦/符卡)：Normal、Extra、Phantasm 编号和角色归属。
- [妖妖梦 Phantasm](https://thwiki.cc/东方妖妖梦/Phantasm)：蓝的中 Boss 符卡与紫的十一符。
- [妖妖梦附带角色设定](https://thwiki.cc/附带文档:东方妖妖梦/角色设定)：莉莉在本作不使用符卡，妖梦的半人半灵设定，幽幽子复活失败及西行妖封印，蓝与橙的式神关系。

## 本轮机制

- 弹幕有实际位置、方向、速度和碰撞。声明符卡不再立刻对随机格或整行扣血。激光先预警，生效期间同一株植物只受击一次。
- 完美冻结让已发出的弹幕停下，再转向释放；咲夜时停期间植物和普通弹幕停止，布置的飞刀在时间恢复后飞出。
- 四重存在由本体加三个独立出弹位置组成；折反射在棋盘上下边界反弹；「之后就一个人都没有了吗？」使用耐久窗口；QED 的环弹随时间加密。
- 爱丽丝采用人偶阵位出弹；蓝的式神「橙」与紫的式神「八云蓝」使用对应角色的协同出弹位置。
- 幽幽子首次击破后进入不能用伤害跳过的反魂蝶终幕，倒计时结束后退场，不再恢复第二条血量或宣称真正复活。
- 原创怨灵接触植物后施加魅惑。正常行动、特殊连射、主动技能及能量豆入口被阻止，原射击冷却保留；魅惑结束后恢复。两层植物都正常计时，覆盖的承载植物不能透过上层植物攻击。死亡植物不再参与魅惑施放、目标选择或正常行动。
- 死亡、阶段切换、蓝到紫的交接和重新开始都会取消所属弹幕及尚未发出的波次；暂停不会推进弹幕。

## 还原边界

名称、角色归属和选定路线可以逐条核对；此实现仍不是原作逐帧复刻。棋盘为横向塔防空间，弹道、数量、射速、伤害、碰撞半径及持续时间经过适配。当前普通攻击以短时符卡轮转运行，并未复制原作逐张独立血条、非符穿插、收卡奖励或所有难度和机体分支。

分身、人偶和式神使用实际出弹位置及角色图像，但未实现原作所有独立受击和使魔无敌规则。芙兰耐久窗口为 9 秒，反魂蝶为 24 秒，均为本作时长。蓝接紫、墓碑地形、普通僵尸援军与猩红长夜持续血线压力属于本作关卡规则，不作为原作剧情或官方符卡设定。

这些差异不能用「完美还原」代称。后续若做原作逐帧校准，需要按明确版本、难度和机体录制并比对逐帧弹道与阶段时序。

覆盖全部已登记技能的运行入口，核对 Extra/Phantasm 顺序、非符与原创来源、真实停弹与反射、穿越碰撞、激光单次伤害、分身出弹、交接清场、耐久终幕和原创魅惑的正常行动隔离与解除。

`godot --path . -s res://scripts/tools/capture_touhou_spells.gd`

原生画面验证工具沿用无存档读写的预览子类，输出桌面、六行棋盘、移动横屏截图至忽略目录 `output/battle-polish/`。
