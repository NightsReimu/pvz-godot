# v1.0.105：庭院界面与符卡宣告

## 玩家可见变化

- 主界面使用庭院配色，主线冒险、每日、无尽和四个功能入口对齐；活动入口保留待开放状态。
- 世界选择同时显示七个世界，点击后预览场景、代表植物、实际通关进度，再点击“进入地图”。未解锁世界可预览，进入按钮继续受原有进度限制。左右按钮、滑动和键盘切换保留。
- 新场景来自一张 4 × 2 图集：白天、夜晚、泳池、浓雾、屋顶、城市、火山，以及菜单背景庭院。原图不含牌匾或文字框；生成记录见 [场景提示词](garden-scene-prompt.md)。
- 图鉴扩大到五列列表和更宽的资料页。基建、抽卡、地图、选卡与其他通用面板共享圆角、轻阴影和更克制的按钮样式；基建待领收益移到升级按钮上方。
- 东方符卡开启时出现约 1.65 秒的主题法阵、环绕图形、向外散开的光点和滑入的符名横幅。灵梦使用御札，魔理沙使用星芒，咲夜使用钟面，幽幽子使用花瓣；23 种角色均有主题映射。仅在有名符卡（包括原创招式）使用宣告，非符不播放。
- 宣告读现有 cast 的 age，不增加战斗计时、伤害、无敌或输入拦截；弹幕与激光在演出上方绘制。暂停冻结时钟，清除 owner 时自动消失。手机横幅有独立最小字号与高度。
