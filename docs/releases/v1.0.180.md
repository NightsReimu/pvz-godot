# v1.0.180 · 风神录融合战斗平衡

风神录六位 Boss（秋静叶、秋穰子、键山雏、河城荷取、犬走椛、射命丸文）的额外伤害由 ×2.5 调整为 ×1.5，并覆盖归属于这些 Boss 的攻击来源。同一攻击的伤害比 v1.0.179 降低 40%。通用东方伤害倍率保持不变，其他东方关卡不受本次系数调整影响。

保留上一版的弹幕密度、出弹节奏、终末援军、弱化道中及正式符卡 87.5% 减伤。射命丸文继续高速飞行、留下残影，龙卷风继续卷走植物子弹；终末登场时全部睡莲退场并保留上层植物。

平衡验证改用真正的融合植物，区分均衡输出、灰烬爆发、防守支援和高耐久组合。植物采用原生生命、护甲和攻击属性，补种实际消耗种子或阳光，大招使用自然充能。新增两套可重复的融合测试入口，覆盖四关四档的成熟阵地诊断，以及从开局真实发牌发展到终末的完整路线。

同种子、同策略的 4-22 Easy / Normal 两档各两个完整路线样本，调整后四条均实际通关；上一版两条通关，两条在 1200 秒采样上限仍未结束。成熟阵地的 48 组对照也显示推进改善；不同阵容和高难度仍可能失败，未结束的样本不记为败局。本次据这些融合战斗结果采用 ×1.5，不继续叠加削弱弹幕或符卡机制。

伤害来源、符卡减伤、阶段流程、融合大招与双生、子弹命中及资源输入回归通过。开发测试和采样输出继续排除在发布包之外。
