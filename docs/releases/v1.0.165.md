# v1.0.165 融合新物种造型与灰烬对空

融合植物改为“一株新植物”的画法，不再是本体上贴材料部件；灰烬类材料融合后保留对空能力。

- **灰烬融合对空**：樱桃炸弹、火爆辣椒、毁灭菇、寒冰菇、地核花、故障坚果与雪绽花参与融合后，爆舱、投掷爆弹以及连锁爆田、不死鸟炎阵、冰火汽爆等大招都能命中气球等空中敌人，融合植物显示「对空」标签。土豆地雷、窝瓜、缠绕海草与大嘴花仍只攻击地面。
- **新物种造型**：全部 11,219 个融合 SVG 重新生成。体型取自武器最鲜明的材料；颜色最鲜明的搭档为全身换上自己的材质，并铺上它的纹理，如樱桃光泽、坚果裂纹、冰晶切面、熔岩裂缝、西瓜条纹、玉米粒、菌斑、魅惑旋纹或电路纹。两种材质同样醒目时保留本体皮肤，搭档以淡纹理出现。例如樱桃射手是带樱桃梗与引信的红色豌豆，坚果豌豆是长出炮管的坚果，冰火菇是冰蓝菌盖铺着火纹。
- **武器长在身上**：没有武器的本体会从嘴部长出搭档的炮管、喷口、颚或透镜，颜色与本体一致；已有炮口的射手不再多长一门炮，而是改装炮口，加上双层炮环、喷口、利齿、钢箍、透镜或火舌；大嘴花等用颚攻击的本体从口中吐出炮管。普通豌豆会把炮管嫁接到更结实的身体上，寒冰、火焰、暗影等特殊射手保持射手体型。
- **表情与元素**：搭档带来表情，例如樱桃与辣椒的怒眉、冰系的霜眉、蘑菇的睡眼、魅惑菇的螺旋眼、电系的电光眼、咖啡豆的瞪眼。融合会继承火、冰、雷、毒、梦蝶、暗影、阳光、爆破、水、风、圣光、治疗、茶、奶等元素，在头旁显示元素徽记；叶片随主元素转为霜绿、秋黄或暗紫。
- **战场动态特效**：融合植物在战场上按元素循环播放头顶火星、飘落雪花、电弧与电光、毒泡、环绕梦蝶、暗影月牙、引信闪光、阳光微粒、水滴、风叶、圣光闪烁、治疗十字和茶奶蒸汽。
- **饰物重做**：樱桃、坚果、高坚果、仙人掌、杨桃、窝瓜、玉米炮、鳄鱼炮、大嘴花、茶杯与牛奶等搭档改为与本体相连的头冠、头盔、尾巴或奶花冠，不再是一株缩小植物立在旁边；同科蘑菇不再附带小蘑菇伙伴，漂浮的层级星标也已去掉。
- **生成管线**：`scripts/tools/build_fusion_parts.py` 从基础植物测量可换色皮肤、眼睛、嘴、炮口和纹理范围，并汇总 `fusion_traits.py` 的体型、材质、纹理、表情、元素数据与 `fusion_accessories.py` 的饰物、武器；运行时递归融合使用同一个组合器。

验证：148 个回归入口通过（134 个 Godot 脚本与 14 个 Python 脚本），新增融合解剖测试覆盖灰烬对空、换皮、纹理、嘴部武器、炮口改装与表情；11,219 个融合 SVG 均可渲染且几何签名唯一；已核对融合花园、战场与大招截图。Windows、macOS、Web、Android 通过既有发布工作流构建，网页试玩同步更新。
