# v1.0.161 融合植物造型重做

融合植物从植物图鉴移除，图鉴只显示玩家拥有的原植物。重做融合素材，解决大量组合共用绿色底座、缩小拼贴原植物而导致轮廓相似的问题。

- **图鉴回归原植物**：固定融合配方、继续共生形态均不再加入列表；此前选中的融合条目会恢复为可见原植物，并修正滚动位置。原有植物的收集、选卡和融合操作保持正常。
- **材料决定造型**：重建全部 10,921 个固定融合 SVG。分别设计坚果堡垒、双果爆舱、菌伞、竹节塔、镜晶花、瓜体投手、玉米穗、玻璃瓜、硫磺豆簇、黑曜蓟、藤蔓、鳄鱼炮与莲台等主体；材料决定轮廓、根系、配色、枝叶及武器部件，取代统一底座上的完整小植物拼贴。
- **命名配方与后续融合**：日晷花、坚城玉米炮、磁轨黑曜炮、日冕花、极光镜阵等使用专门的结构方案；蜂蜜花有蜂巢结构，砂莲有砂托，进阶日光豌豆与豌豆堡垒增加日冕和城垛。继续融合实时生成新 SVG，固定与共生形态共用同一个造型生成器。
- **实战显示**：射口保持朝右，双向植物保留背向射口。取消统一的闲置环绕光圈，阳光与火焰材料各自显示微光和余烬；爆舱充能动画对应新模型上的装填位置。保留独立武器、投掷弹道、范围爆舱、反弹等原材料能力及大招。

验证：142/142 个完整游戏回归入口通过；10,921 个固定 SVG 均可渲染，按实际几何而非名称或配色检查无重复。新增原植物图鉴、旧选择恢复和小尺寸轮廓辨识验证；同一豌豆材料的八组投手模型轮廓差异最低 0.219、平均 0.375（上一版分别为 0.030 和 0.166）。完成 1600×900 / 844×390 原生战场、种子预融合、融合工具、图鉴以及模型画廊截图核对。

发布：Windows、macOS、Web、Android 四个平台，网页试玩同步更新。
