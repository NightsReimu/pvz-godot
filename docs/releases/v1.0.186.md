# v1.0.186 · 永琳与辉夜符卡还原、按难度校准与演出优化

**八意永琳 / 蓬莱山辉夜（3-24）按原作重做**
- 永琳：「壶中的天地」的使魔围成圆阵并缓缓收拢；「神代的记忆 / 天人的族谱」用激光夹住目标；「生命游戏 / Rising Game」中，设置弹在草坪远端的格子里按生命游戏规则一代代繁衍；「Omoikane」的 winder 弹流来回摆动；「Apollo 13」是两组随机角度交错的弹幕；「天文密葬法」的大弹依次瞄准目标的右、左、正中；「蓬莱之药」分五段变换，全程有扫动的激光。
- 辉夜：龙颈之玉的五色宝玉被抛出后回落，并有瞄准激光；佛御石之钵用随机激光封路，星弹缓缓落下；火鼠的皮衣是一圈火焰加使魔激光；燕的子安贝是慢慢展开的激光与交叉弹；蓬莱的弹枝是会在边缘反弹的七色弹。
- 五张「永夜归返」各不相同：初月系的中弹先飞向上下再转向植物，子之刻是随机交差环，丑之刻是交叉弹流，寅之刻是偏开目标的斜弹列，最后一张不停更换弹种，左右交替弯曲。
- 施法时永琳身后有弓，生命游戏显示格子；辉夜身边环绕五个宝物，永夜归返时天上的月亮逐段变化。

**新增原作的 Hard / Lunatic 道中符卡**
- 2-25 道中的琪露诺：霜符「Frost Columns」。
- 2-27 的爱丽丝开场：操符「少女文乐」，五个人偶牵着丝线起舞。

**演出**
- 灵梦的阴阳玉、魔理沙发光的八卦炉（火花系符卡会蓄满）、铃仙的狂气之瞳波纹、妹红的火焰凤翼、萃香的葫芦与雾等施法效果。
- 莱瓦汀的炎剑更醒目；夜盲时草坪远端更暗。

**性能**：子弹按数量自动降低绘制细节，弹幕密集时的帧时间与 v1.0.184 持平或更低。

**平衡**：每张卡的伤害系数现在可以按难度分别设置，并保证单发伤害随难度上升。与 v1.0.184 对照的 467 个卡 / 难度组合中，449 个的伤害压力在 ±25% 以内（v1.0.185 为 391 个中的 342 个）。
