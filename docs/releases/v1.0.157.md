# v1.0.157 — 融合僵尸与保龄球阵营修复

- 修复普通坚果、强化坚果、普通芒果和强化芒果保龄球直接攻击魅惑僵尸的问题。碰撞入口统一检查敌我阵营；友军不会掉生命或护具耐久、触发冲击与溅射、消耗命中次数或令球换行弹跳。球穿过友军后仍可命中后方敌人，敌方溅射和弹跳保留。
- 新增 163 种装备融合组合，覆盖 50 个原始僵尸定义，包括路障铁门、橄榄球铁门、路障忍者、铁桶忍者铁门、头盔撑杆、铁桶舞王、铁桶潜水、铁桶巫师及火山角色。融合保留原型的行动与技能。
- 头戴护具、手持护具和本体分别使用橙金、蓝、红血条。普通正面攻击依次打手持护具、头戴护具、本体；喷雾、回旋镖、穿透弹丸和光束绕过手持护具后仍会消耗头戴护具。背后攻击兼容魅惑后的朝向。
- 每件新增护具有独立耐久、破损和脱落表现。磁力菇每次移除一件金属装备；移除头盔不取消撑杆、跳跳、忍者与召唤等原型技能。护具被击破时的伤害溢出保持正确，不重复计算本体伤害。
- 无尽模式从第 6 波起按装备强度逐步加入融合僵尸，对符合条件的原型以 18% 概率替换；双护具及暗黑头盔在后续波次开放。护具耐久随无尽强度增长，图鉴提供融合原型、分层耐久与克制说明。
- 统一喷雾、回旋镖、莲枪弹幕及激光、镜面、太阳、等离子、龙息、回响等穿透技能的护具判定，覆盖普通攻击、点击大招和植物能量路径。
- Windows、macOS、Web、Android 版本同步为 `1.0.157`，Android 版本号 `10157`。

验证：保龄球阵营测试先复现误伤，再验证四种球的 12 个场景，包括普通友军、双护具友军、友军与敌人重叠、敌方溅射和换行弹跳。融合测试覆盖全部 163 种组合、实际攻击及大招、伤害溢出、磁力移除、角色技能、无尽准入和禁用关卡限制。上一轮 135 个验证入口已通过；本轮补充保龄球回归并复测相关战斗、状态、技能与发布配置。原生画面检查覆盖完整、破损、移除护具和桌面/手机战场。
