- 替换露娜萨、梅露兰、莉莉卡的三张素材表，逐个分离为 72 张独立透明姿态。按每个姿态的实际轮廓分配像素，保留原图透明边缘与朝向，统一角色身体高度；原始表、裁剪坐标和哈希保存在素材清单中。
- 2-28 三姐妹同时现身，分处不同位置，各自播放动作、蓄力与出弹。攻击任意一人均扣共享血量，阶段进度、击杀和奖励只结算一次；同一次爆炸覆盖多人不会重复扣血。普通射击、穿透、回旋镖、投掷、追踪、激光与范围攻击使用相同的三人位置。
- 补全《东方妖妖梦》四面的六组符卡：骚符、小提琴独奏、号角独奏、键盘独奏、棱镜协奏曲和灵车大协奏曲。Easy、Normal、Hard、Lunatic 对应原作 045–068 的名称与编号，高难度保留本作新增的三重奏追击、交叉弹和预警音束。说明见下方参考与改编。
- 新增 21 张由内置图像生成工具绘制的透明技能插画，覆盖暗夜、妖精、虹龙、禁书、七曜、刻针、猩红枪阵、人偶、春花、三种乐器、狐符、萤虫、夜雀、史书、半兽史迹、幸运兔、月之幻视、药术与五种难题。连同现有六张插画，29 种东方 Boss 均有对应表现。四位无命名符卡的道中 Boss 使用技能光环，不添加虚构原作符卡。
- 蓄力渐入、法阵展开、持续脉动、消散与技能计时同步；三姐妹各自使用小提琴、号角和键盘插画，人偶阵与各类激光发射口增加局部点缀。插画在植物、弹幕和预警下方绘制，限制范围、透明度和额外绘制数量；不由插画额外产生伤害。
- 世界菜单和图鉴预热角色帧，进入关卡时加载对应的大幅技能插画。移动端所有东方 Boss 的蓄力提示统一按战场尺寸缩放。
- 修正旧回归测试对素材来源、三姐妹路线数量、露米娅身高和琪露诺悬浮冰晶的过时假设；保留裁剪归属、透明边界、实际身体高度与技能序列检查。
- Windows、macOS、Web、Android 版本同步为 `1.0.156`，Android 版本号 `10156`。

## 原作参考与本作改编

符卡名称与四难度编号依据原作文本的 [TH07 翻译档](https://www.thpatch.net/wiki/Th07/Spell_cards)。原作独奏路线会随自机及领奏选择分支；本作按用户要求让三姐妹始终可见且都能受击，将三条独奏合并为必经阶段。小提琴使用缓慢弯曲弦流，号角使用扩散音弹和有预警的贯穿音束，键盘使用交替和弦与回响，合奏使用三个实际位置的交织音弹。弹幕几何、命中与范围伤害为横向植物塔防改编，并非原作逐帧一比一模拟。

全部生成模式为内置 image generation；原始提示词、输出来源和文件哈希见 [提示词记录](../touhou-spell-art-prompts.json) 与 [素材清单](../../art/touhou_spell_fx/manifest.json)。三张用户原图归档见 [三姐妹裁剪清单](../../art/source_sheets/prismriver_refresh/manifest.json)。

验证：134 项仓库回归及针对变更的补充复测通过。72 帧像素归属与原始透明度全量检查、三人实际射击/回旋镖/投掷索敌、共享血量与范围攻击去重、冻结、四难度符卡编号和发射位置、阶段清理通过。27 张插画的文件及 Godot 导入透明度哈希一致；134 张符卡的视觉计时与只读绘制检查通过。桌面 1600×900、手机横屏 844×390 原生截图覆盖所有 29 种 Boss 的蓄力、展开与持续阶段，并额外检查三人独奏和最终合奏。
