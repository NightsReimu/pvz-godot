# v1.0.123 植物、僵尸与战斗视觉优化

- 重绘小喷菇、阳光菇、大喷菇和火炬树桩的矢量造型：增加菌盖、菌褶、表情、树皮、树根和分层火焰，阳光菇保留幼年与成熟形态。战场、卡片和图鉴共用新造型。
- 普通僵尸增加衣领和裤子补丁；路障、铁桶、报纸在护甲低于一半时呈现破损，护甲耗尽后保留原有脱落表现。
- 种子卡与选卡界面统一名称、头像、费用排版，提高手机横屏的头像可见度；强化徽章移出名称行，冷却遮罩只覆盖头像，费用不足以颜色提示。
- 血条随单位尺寸缩放，增加深色边缘；植物护甲改用蓝色，睡眠标记也随小屏单位缩放。
- 区分豌豆、冰晶、火焰和护甲命中；缩小普通命中光晕与粒子，避免旧贴图覆盖元素形状，普通火焰连射不再持续震屏。

本次调整侧重视觉和反馈，战斗伤害、射速、关卡配置与存档结构保持兼容。

## 验证

桌面 1600×900、1280×720 及手机横屏 1000×450、844×390 的战斗截图；额外检查强化/冷却卡片、选卡、幼年阳光菇、护甲完好/破损/脱落和元素命中。

回归范围：战斗反馈、植物状态与攻击范围、火焰回旋镖、传送带、Boss 战斗流程、四难度、小游戏、布局与触摸、全植物/僵尸图像入口、运行模块与启动。渲染回归覆盖 12 组轮廓、10 组状态、3 种元素命中差异和 3 组动作。

同时修复旧回归工具：Boss 图像校验改为逐个核对当前 27 位角色，模块测试释放临时界面对象，避免退出时泄漏。
