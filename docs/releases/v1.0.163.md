# v1.0.163 古代世界、天气系统与融合造型重做

新增第八世界「古代世界」与天气系统，五株新植物、三种古代僵尸；融合植物改用基础植物同一套画法重新生成，融合特效全部重绘，并修正一批不合理的融合本体。

- **古代世界 8-1 ~ 8-5**：鸟居、古塔与石灯笼环绕的古都庭院，7-20 通关后开放。每关登场一株新植物，可在本关直接使用并永久加入收藏；困难模式拥有独立的古代敌群。旅行手册、主页与世界卡片新增古代世界插画，世界列表改为八个目的地。
- **天气系统**：晴天、烈日、细雨、雷暴、东风、大雾按关卡日程轮换，战场旁的天气牌显示当前天气、效果与剩余时间，切换时有渐变与横幅。烈日阳光 +25%、火焰 +20%、武士迟缓；细雨火焰 -40%、雷电 +25%、茶渍扩散；雷暴约每 7 秒落雷并优先劈向铁甲，电系出手 +30%；东风僵尸 +20%、蒲公英多吹一枚孢子；大雾让直射植物只能锁定 4 格。
- **五株新植物**：
  - 蒲公英：孢子缓缓升空，再从天而降命中本行最前方敌人，越过手持盾并可击落空中单位。
  - 茉莉花茶：浇灌前方 3×3，伤害较低，但腐蚀草地，站在上面的僵尸「虚弱」，受到的全部伤害 +30%。
  - 金铲铲牛奶：一次性，奶浪冲刷整行，每只僵尸 1000 伤害并击退一格；首领只受伤害。
  - 轮回眼睛花：一次性，复活 10 秒内倒下的植物；原格已有植物时直接参与融合，没有配方则就近安置。
  - 电眼菜问：向前后近身快速出拳，每第四拳放出连锁闪电。
- **三种古代僵尸**：古代武士（2100 耐久、接触即居合重斩、大铠分段剥落）；古代法师（把前方随机两株植物变成小羊，击败法师即解除）；军师（羽扇改写天气 12 秒，指挥同伴转向防守最薄弱的相邻行，有同伴时坐镇后方）。
- **新植物参与融合**：一次性的牛奶和轮回眼在融合中化为独立充能的奶舱与轮回之眼；新增茉莉奶茶、雷鸣菜问、风絮蒲公英、涅槃轮回树、金铲拿铁五个命名配方及其盛放形态，新增「茶香满庭」「轮回再临」大招。
- **融合造型重做**：全部 11,219 个固定融合 SVG 改用基础植物的描边、渐变与五官：由最适合作身体的材料提供完整本体并向搭档色调过渡，其余材料长出各自的标志部件——豌豆炮口、花瓣光环、菌盖、坚果护甲、投石臂、莲座、火冠、晶簇等；同种材料叠加长出双头与三头，命名配方戴上金色花饰。递归共生沿用同一个生成器。
- **融合特效重绘**：全部 33 种融合大招、爆舱、光束与种植绽放改为分层光晕、实心火舌、雪花、闪电、蝴蝶、护盾与金属碎片等元素造型，烈焰、寒霜、雷电、毒蚀、梦蝶各有色板。
- **基础植物优化**：卷心菜、玉米、西瓜、天窗瓜、龙泡泡、喷气冬瓜与剧毒口香糖投手长出各自作物的身体轮廓，不再共用同一个弹射底座。
- **融合修正**：融合本体此前按名字字母顺序选择，地刺、海草、棉花糖、海蘑菇、樱桃炸弹等会成为本体，导致荆棘坚果与「地刺·向日葵」等无法被啃食、部分组合被锁在水路或云格。现在优先选择可正常种植、可被啃食、非一次性的材料作本体。保龄球专用坚果只存在于禁止融合的保龄球小游戏，不再生成无法获得的配方。

验证：145/145 个回归入口通过，新增古代世界测试覆盖解锁顺序、天气轮换与效果、五株植物、三种僵尸、命名配方与本体修正。11,219 个融合 SVG 全部可渲染且几何签名唯一；完成 1600×900、844×390 战场、六种天气、旅行手册、主页与图鉴截图核对。

Windows、macOS、Web、Android 四平台发行；网页试玩同步更新。
