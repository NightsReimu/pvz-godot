# v1.0.151 — 红魔乡 Boss 素材更新

- 露米娅、大妖精、琪露诺、红美玲、小恶魔、帕秋莉、十六夜咲夜、蕾米莉亚与芙兰朵露换用新提供的九张素材。
- 按各个姿态的实际轮廓分别提取透明子图，独立保存 216 个运行帧。宽幅冰晶、翅膀、武器和斩击完整保留，针对蝴蝶、新月、飞刀弧线等越过名义格子边界的特效单独校正归属。
- 露米娅原图包含 30 个位置，重新排列运行帧；纯暗斩、额外步态和倒地姿态另存为 8 个独立素材。暗斩作为施法叠加特效使用。
- 重新对应九位 Boss 的待机、移动、技能与受击动作，统一脚部锚点与 180 像素人物基准高度，保留素材原有朝向。
- 保存透明源图、原图与源图 SHA-256、各姿态边界及锚点记录，提供可重复运行的导入工具。
- 项目版本与四个平台的导出预设同步到 `1.0.151`，Android 版本号为 `10151`。

验证：216 帧人物完整性、透明边缘、宽幅特效与邻帧污染检查通过；技能与受击动作、运行时透明度保留、资源预热、全部东方 Boss 高度、单位图鉴识别、启动和发布配置回归通过。使用 Godot 4.6 原生渲染检查待机、符卡、受击、暗斩叠加与图鉴缩略图。

素材处理使用内置 imagegen 工具提取透明背景，然后通过 `scripts/tools/import_scarlet_sprite_cutouts.py` 按独立透明连通区域分离各姿态。透明源图与完整裁切记录位于 `art/source_sheets/scarlet_refresh/`，运行帧位于各角色的 `art/角色名/` 目录。

透明处理提示：仅移除模糊背景并输出透明 alpha；保持相同画布、姿态、位置、朝向、服装、独立粒子、武器和符卡特效；不重绘或重新排列角色。
