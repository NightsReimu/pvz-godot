# v1.0.148 — 困难配置绑定具体关卡

- 困难配置现在以完整关卡 ID（例如 `1-1`、`1-S4`、`7-20`）绑定设计，不再只按世界共用一套逻辑。
- 每个具体关卡根据自身编号、普通敌群和地形选择额外僵尸，分支 S 关卡也有独立设计编号。
- 困难按钮会显示该关卡的专属压力主题，出怪插入点和后期波次压力随关卡编号变化。
- 继续保证每关至少 2 倍普通僵尸事件与至少 2 倍波数，东方关卡仍使用原有难度系统。

验证：`level_difficulty_test.gd` 对 167 个非东方关卡逐关检查配置绑定、僵尸数量和波数，0 failure；`game_boot_test.gd` 通过。
