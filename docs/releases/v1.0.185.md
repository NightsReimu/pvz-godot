# v1.0.185 · 红魔乡、妖妖梦、永夜抄符卡还原与演出美化

风神录以外的东方 Boss（1-17～1-23、2-25～2-31、3-19～3-21）按原作重做了符卡弹幕，按难度换上原作各自的符卡，统一美化了子弹、激光、宣言和施法动画。

**按难度使用原作符卡**
- Hard / Lunatic 不再沿用 Normal 的符卡：琪露诺的「Hailstorm」，美铃的「Selaginella 9」「华想梦葛」「彩光乱舞」，帕秋莉的「Agni Shine上级」「Trilithon Shake」「Forest Blaze」，咲夜的「幻惑Misdirection」「Jack the Ludo Bile」「The World」「杀人玩偶」，露米娅的「Moonlight Ray」。
- 妖妖梦的蕾蒂、橙、爱丽丝、妖梦、幽幽子按难度使用各自的编号和名称（例如白符「Undulation Ray」、怪符「Table Turning」、阴阳「晴明大纹」、诅咒「上吊的蓬莱人偶」、天神剑「三魂七魄」）。骚灵三姐妹 Hard / Lunatic 的终段改为骚葬「Stygian Riverside」。
- 莉格露和米斯蒂娅之前的符卡表有误（日文名、重复、原作不存在的符卡），现在按永夜抄原表重排，并以隐虫「永夜蛰居」、夜雀「午夜的合唱指挥」收尾。慧音的译名也按原作更正。

**红魔乡**
- 冰符「Icicle Fall」：冰柱先飞向草坪上下边缘，再落向植物，形成两道斜墙。冻符「Perfect Freeze」：乱射的子弹冻结时变白，冻结期间琪露诺瞄准射击，解冻后慢慢起步、转向任意方向。
- 美铃：花形弹幕、七色旋转风铃、从两侧落下的彩雨、全色台风。
- 帕秋莉：五行元素球绕身旋转；会弯曲的火球环、接近植物时变轨的石块、两个弹源交织的水银之毒、皇家烈焰的大日轮、贤者之石的五色水晶。
- 咲夜：Misdirection 的苦无会折返扑向植物，她在三处瞬移投刀；Clock Corpse 先乱射再停止时间；Luna Clock / The World 在时停中把飞刀布满植物四周，时间恢复时一起射出。
- 蕾米莉亚：草坪上的六芒星激光、针山、弗拉德·采佩什的诅咒中螺旋飞刀留下的红弹、Scarlet Shoot 的大弹群，Red Magic 的大玉会反弹并沿途洒落小弹。
- 芙兰：使魔绕场的蔓越莓陷阱、横扫整片草坪的莱瓦汀炎剑、笼目的绿弹格子、恋之迷宫的旋转缺口、星虹雨、反弹两次的折反射、钟面上转动的激光指针、越来越密的 495 年波纹。

**妖妖梦**
- 蕾蒂会停顿后再加速的雪弹螺旋、凋谢的雪花；橙在场上跳跃、留下孵化的蛋团、画出五芒星；爱丽丝的人偶各自发射并有丝线相连，上海人偶的激光跟着人偶移动。
- 妖梦的剑气悬停后扑向植物，二百由旬的大玉被斩成米弹，悟入幻想的米弹从草坪下沿升起。
- 幽幽子的燕尾蝶弹幕会展开成蝴蝶轮廓，西行妖洒下旋转的花瓣，弘川的幽灵从草坪边缘升起；反魂蝶的蝶翼越接近满开越密。
- 八云蓝的九尾弹、卍字符札臂、交叉激光、四面合围；八云紫的隙间、界线、激光网格与合拢的弹幕结界。

**永夜抄**
- 莉格露的萤火会停下闪烁再扑向植物，蛰居的萤火虫先无害地伏在草坪上再一起苏醒；米斯蒂娅的蛾子沿途撒鳞粉，鹰符俯冲掠过草坪，夜盲时草坪远端变暗。

**技能**：咲夜只在时间类符卡（Clock Corpse、Luna Clock / The World、操弄玩偶）停止时间，普通攻击与 Misdirection 不再开场时停。

**演出**：子弹全部重绘（白芯彩边的圆弹与大玉、米粒、苦无、银刀、针、冰片、符札、旋转星弹、音符、扇动的蝴蝶与蛾、樱花瓣、火弹、鳞弹、萤火、幽灵、蝙蝠等），冻结时变白。激光带闪烁预告线和起点光团。30 位 Boss 有了各自的宣言符号与魔法阵，正式符卡期间脚下展开魔法阵、身后有光晕；施法时还有露米娅的黑暗球、琪露诺的霜光、帕秋莉的元素球、咲夜的钟面、蕾米莉亚的红月、芙兰的炎剑与钟面、幽幽子的扇面与西行妖、蓝的九尾、紫的隙间等。灵梦、魔理沙、铃仙、永琳、辉夜、妹红和萃香的弹幕同样换上了新的子弹、激光、宣言和光环。

**平衡**：每张卡的伤害压力按 v1.0.184 校准。391 个卡 / 难度组合的中位比值为 1.00，342 个在 ±25% 以内。
