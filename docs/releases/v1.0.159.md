# v1.0.159 全植物融合与共生大招

之前部分融合植物的大招只显示动画，辅助底座还会改变攻击派发与睡眠状态，导致一些混合植物不攻击。本版重做融合规则、技能执行和图鉴说明，逐项验证实际游戏状态。

- **任意两种都能合成**：覆盖 146 个原植物定义的全部 10,731 种无序配对（包括保龄球专用坚果；普通可选种子为 145 种）。支持原种与融合形态、不同融合形态继续组合，保留双头向日葵、双发和机枪等经典命名配方。
- **大招具有实际作用**：根据材料组合 31 类技能。齐射、投弹和回旋刃分三轮释放；星阵向五行发射穿透弹；激光和磁轨束贯穿手持护具但仍需击破头戴护具。冰火材料产生三次汽爆，毒蝶留下持续毒蚀与毒爆，根网控制远处敌群，风系可击落气球并清雾。
- **支援大招能帮助原种与融合植物**：治疗、护盾、短暂无敌、十秒加速、八秒回春、蘑菇唤醒和阳光产出都有独立执行。幽灵游行补足最多三名友军；梦蝶可魅惑普通僵尸，Boss 保持魅惑免疫。攻击、爆炸、状态技能和果轮均跳过魅惑友军。
- **独立建模和动画**：10,921 个固定形态各有独立 SVG 文件，持续融合生成对应的独立 SVG 几何；模型结合材料的器官、权重和攻击结构，火炬、杨桃、阳光菇及南瓜保留可辨识轮廓。大招使用独立的雷电、星阵、刀刃、果轮、领域、冰晶、炎阵、蝶群、护盾和根网动画，持续融合时继承相应技能。图鉴大招说明可翻页或滚轮阅读，避免多技能说明被截断。
- **修复攻击和状态**：被动底座不再吞掉远程攻击；具有日间材料的混合蘑菇能够醒着攻击；南瓜基底合成时补上自身护甲，避免立即被移除。日光豌豆同时攻击和产阳光；睡莲、花盆、咖啡与火炬的点击/能量豆大招提供实际收益，原种加速按时结束。
- **使用方式**：叠种、融合工具合并两株，或预融合两张种子。普通咖啡唤醒与南瓜附着仍沿用原手势，要融合请用融合工具。地形、种子费用、传送带实际卡片、控制与封印限制继续生效。
- **运行开销**：图鉴按拥有植物和融合目录变化缓存，融合纹理缓存限制为 256 项。单种材料权重最多八份，数值有上限；所有有效材料组合仍有配方。

验证：完整游戏回归 140 个入口；对全部 10,921 个固定形态检查普通攻击与大招的实际收益、友军安全及 SVG 渲染；覆盖任意原种配对、递归融合、击中敌人的远程弹、各类技能效果、底座合并和状态计时。核对 1600×900 桌面及 844×390 手机的实战、融合预览和图鉴画面。

发布：Windows、macOS、Web、Android 四个平台，网页试玩同步更新。
