# v1.0.110 · 永夜抄六面 A：八意永琳

- 新增泳池世界东方关卡 **3-24-a「壶中的天地」**，通过 3-23 解锁。道中击退低血量永琳后继续推进，在终末前穿过回廊尽头，进入巨月下的天空战场；使用两首新音乐及用户提供的 24 帧永琳素材。
- 按永夜抄六面 A 的符卡顺序与难度分支设计六组原作符卡，Easy / Normal / Hard / Lunatic 分别为 **6 / 7 / 8 / 9 阶段**。高难度追加狂暴药剂、禁疗处方和混合世界符卡，Lunatic 使用自选植物。
- 终末随机映出水域、火山和屋顶；格子提前 **2 秒预警**，变化持续 **10 秒**。植物不会因地形变化直接消失，睡莲、花盆、木塞与冷却机制可应对新地形。狂暴与禁疗的药瓶可以击碎，植物自身发动大招仍回满血。
- 本关从各世界普通战斗僵尸中混编敌群，包括水生与机械单位。新增星弹精灵、分裂毛玉及飞艇玉兔：飞艇可被地面植物击落，飞至左数第三列后返航，沿途投放防御玉兔，不啃食、不进家。
- 东方传送带中的治愈葫芦相对权重降低 **30%**。葫芦只回血，不提供护甲、免疫或攻击；修复辅助层回血逻辑。

验证：关卡配置、四难度完整阶段、真实道中/终末 BGM、地形预警与恢复、禁疗和药瓶解除、飞艇往返/地面命中、召唤上限、暂停与重开、1600×900 和 844×390 画面，以及相关东方、葫芦、传送带、火山和抽卡植物回归检查。

原作符卡名称与分支有出处；横向弹道、伤害、格子变化及药瓶属于本作塔防适配与原创玩法。
