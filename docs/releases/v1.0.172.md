# v1.0.172 · 东方 4-19：红枫与丰穰

完成《东方风神录》一面主题的 4-19：秋静叶道中、秋穰子终末，四档难度，六行红枫旱地，没有水或浓雾。4-18 通关后从第四世界地图进入独立东方场景。

## 关卡与素材

- 独立红枫林背景、黄褐旱地格和轻量飘叶，桌面及移动横屏均保留六行。
- 使用提供的两人各24帧素材，保留原始透明像素并校准脚部锚点。
- 提供的道中 BGM 从开场持续至秋静叶退场；只有秋穰子终末登场后才切换终末 BGM。两首音乐均循环播放。
- E/N/H 使用旱地传送带，L 使用自选卡。双发、三线、瓜投手、火炬、坚果、葫芦、伞叶、仙人掌、灰烬等各有用途；Boss 战期间继续出现普通陆地僵尸及少量气球。

## 原作与原创符卡

| 难度 | 秋静叶道中 | 秋穰子原作符卡 | 原创符卡 / 终末阶段 |
|---|---|---|---|
| Easy | 弱化非符 | 秋符「秋之天空」、丰符「大年收获者」 | 1张 / 3阶段 |
| Normal | 弱化非符 | 同主题的 Normal 原作编号 | 2张 / 4阶段 |
| Hard | 非符、叶符「狂乱的落叶」 | 秋符「秋之天空与少女之心」、丰收「谷物神的允诺」 | 3张 / 5阶段 |
| Lunatic | 非符、叶符「狂乱的落叶」 | 同主题的 Lunatic 原作编号 | 4张 / 6阶段 |

采用本作东方 Boss 的分阶段生命条、非符、符卡宣言、专属动作、真实弹幕碰撞与阶段清理。道中保持 v170 的弱化生命规模，终末沿用强化生命值。

原创符卡明确标注「原创」并逐档保留：

- **秋收「红枫田垄的收获祭」**：金穗预警后短暂加快标记格植物行动，收割前出现红圈；有限局部伤害，能量豆可清本行。
- **供奉「阳光贡仓的秋日祭」**：预警后出现可被普通或融合攻击击破的实体贡仓。每4秒有限治疗附近普通僵尸，真实击杀返25阳光一次；过期、换符、主人退场不奖励。
- **枫阵「交错六畦的红叶毯」**：选中格短时减速，覆盖原生、融合及支援植物的行动时钟，能量豆扫净本行。
- **丰穰「六畦同庆的秋日宴」**：交替催熟、落叶毯和贡仓，保留12处田垄、3个贡仓的总上限。

红叶缓弧、秋空扇阵、双心交织、金色谷粒及丰收穗阵都有独立弹体和读条。所有田垄至少1秒预警，随暂停、时间停止、符卡及主人生命状态正确推进或清理。
