# v1.0.147 — 困难模式分关卡设计

- 困难模式现在按关卡编号和世界分别选择敌群方案。
- 白天侧重路障、撑杆跳、铁门和橄榄球；夜晚加入报纸、舞王、矿工、篮球和魅惑盒；泳池按关卡轮换鸭泳圈、浮圈、潜水、海豚和雪橇；浓雾加入气球、龙卷、忍者、末影和巫师；屋顶加入梯子、蹦极、投石车、巨人和滚筒；城市加入程序员、路由、盾卫、医疗、破坏者和裂隙敌人；火山加入余烬、玄武岩、窑工、硫磺、晶簇和喷口敌人。
- 每个阶段使用不同的额外敌人组合、插入节奏和后期波次压力，并把组合说明显示在困难模式按钮下方。
- 继续保证每关至少 2 倍普通僵尸事件和至少 2 倍波数；原关卡 Boss 仍在最后阶段出现。
- 东方关卡不进入这套分关卡困难逻辑。

验证：`level_difficulty_test.gd` 检查 167 个非东方关卡通过；`game_boot_test.gd`、`plant_effect_alignment_test.gd`、`effect_glow_test.gd`、`ui_surface_polish_test.gd`、`vector_art_assets_test.gd` 均通过。
