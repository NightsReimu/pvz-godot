# v1.0.153 — 幻想庭院界面更新

- 主页面重做为手绘庭院告示板：新的庭院插画、游戏标题、纸张、雕刻木牌与悬挂灯笼，入口配有植物伙伴与七个世界的风景邮票。
- 世界选择重做为旅行手册，展示七个目的地、完整场景插画、本页植物、真实解锁与通关进度。切换场景时渐变，水面、夜间、城市和火山分别配有不同环境粒子。
- 新增平滑悬停、按压反馈、分批入场、灯笼摆动、植物轻摇、落叶、萤火与点击粒子。动画在 Godot 中实时运行，粒子有数量与寿命限制，大时间步不会让弹性动画失控。
- 图鉴、小游戏、选卡、每日、基建、强化与召唤页面接入插画材质；战斗界面、暂停、难度选择、结果窗口与加载页统一按钮和面板风格。强化植物配有呼吸光环，召唤角色轻摇，结果窗口弹出时缩放淡入。
- 修正普通难度弹窗在手机横屏下的绘制坐标，保持其按钮显示与实际点击位置一致；修复部分支线没有解锁植物字段时地图详情绘制报错。沿用原来的导航、解锁、选卡、存档及关卡规则。
- 新插画使用内置图像生成工具生成，原始 PNG 与透明通道保持不变，保存于 `art/storybook_ui/`；最终提示词和 SHA-256 记录于 `docs/storybook-ui-prompts.json`。材质通过引擎九宫格缩放，文字仍由游戏实时排版。
- 项目与四个平台导出版本同步到 `1.0.153`，Android 版本号为 `10153`。

验证：24 项回归检查覆盖交互状态、粒子预算、弹性稳定性、弹窗构建、资源透明度、导航、布局、手机缩放、触屏选卡、图鉴、每日、基建、强化、召唤、暂停、难度、启动与更新流程。Godot 4.6 原生渲染检查 18 种页面状态在五个分辨率下的 90 张截图，额外检查桌面与手机的难度和结果窗口；主页面、世界选择与小游戏捕获 72 帧，并确认画面随动画发生实际变化。

发布包提供 Windows、macOS、Web 与 Android 四个平台。
