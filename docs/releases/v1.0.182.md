# v1.0.182 · 早苗道中节奏与风神录伤害调整

4-23 道中东风谷早苗改为在**战斗进度达到 50%**时登场，交战期间进度条停在 50%，击退后继续推进。移除固定 105 秒出场条件，也修正了终末提前排入队列时强制召出道中 Boss 的旁路。

神社道中缩至适中长度：大波标记由五次减到四次，事件由 24 项减到 18 项，终末的最早排程从 300 秒提前到 **180 秒**。前半保留融合阵容的准备时间，仍需击退道中 Boss 和推进普通敌群，完整终末才会登场。

移除风神录七位 Boss（秋静叶、秋穰子、键山雏、河城荷取、犬走椛、射命丸文、东风谷早苗）及所属攻击的额外 **×1.5** 伤害加成，回到所有东方 Boss 共用的伤害倍率。同一攻击比 v1.0.181 降低约 **33.3%**。弹幕密度、出弹节奏、正式符卡 87.5% 减伤、原有技能和持续增援保留。

四档进度触发、道中与终末音乐、伤害来源、符卡减伤、旧风神录关卡和融合资源回归通过。真实 Easy 融合路线在进度跨过 50% 时出现道中，期间显示一直为 50%；完整七阶段在 586.30 秒通关，无小推车消耗，所有材料和大招充能来自原生规则。

发行包继续使用修复密集绘制崩溃的 Godot 4.6.3。源码使用该版本或更新版本时，可直接运行 `godot --path .`。
