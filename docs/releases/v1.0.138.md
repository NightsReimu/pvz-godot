# v1.0.138 — 单位美术重绘与永夜抄 EX

本次重新检查所有植物和僵尸的实机表现，并修复最近几轮迭代中的攻击与绘制问题。

![v1.0.138 实战预览](https://raw.githubusercontent.com/NightsReimu/pvz-godot/v1.0.138/docs/readme/unit-art-v138.png)

## 单位美术

- 检查全部 **146 种植物、129 种僵尸与 Boss**；为其中 **144 种植物重新绘制 SVG**。采用曲线叶片、分层花瓣、蘑菇菌褶、木纹、冰晶和明确的武器轮廓，减少遮脸的装饰光线。战场、选卡、图鉴与预览统一使用新资源。
- 保留坚果破损、幼年阳光菇、胆小菇躲藏、食人花咀嚼、地雷布设等状态；火炬树桩保留动态火焰，坚果保龄球使用新坚果的派生造型。
- 重做共享僵尸身体、脸部、衣领、鞋子与手部，补齐特殊僵尸和载具驾驶员的五官。路障、铁桶和橄榄球头盔随护甲受损改变外观；修正巫师帽和舞王头发遮住眼睛的问题。
- 调整大体型、撑杆和悬吊单位的图鉴取景；把角色脚下的大圆影改为贴地椭圆。东方角色继续使用现有角色动作素材，统一人物显示高度。

## 战斗修复

- 修复魔术花的重复分支，让月陨、棱镜、暗影、回旋竹和集束弹实际执行各自的特殊行为；修复误改其他植物子弹和部分随机弹未吃伤害倍率的问题。
- 脉冲灯球的 5×5、提灯花的 3×3 攻击按实际格子显示范围；植物攻击对僵尸和障碍物采用一致的方形区域。棋盘外远处僵尸不会再因列号被钳制而误受伤。
- 修正月陨与集束弹的格子坐标；修正螃蟹、幼蟹和熔岩尸王特效重复叠加纵坐标造成的绘制偏移。
- 永琳、辉夜的高难度追加招式分别采用交叉攻击与多点阵地弹幕，避免招式名称不同但攻击相同。

## 3-25 永夜抄 Extra

- 通过 3-24-a 与 3-24-b 后解锁，提供 **EX / EX+** 两档。深夜竹林保持低亮度，妹红登场后渐亮；接入用户提供的道中、终末 BGM 和两组 24 帧人物动作。
- 道中 Boss 为上白泽慧音半兽形态，参考「旧秘境史」「一条归桥」「新幻想史」。必须击破全部道中阶段，才能推进终末。
- 终末藤原妹红参考永夜抄 Extra 十张常规符卡与 Last Spell「Imperishable Shooting」，涵盖「月之岩笠的诅咒」「徐福时空」「正直者之死」「不死鸟之尾」「凯风快晴」「蓬莱人形」等主题；具体原作名称、编号与塔防适配见仓库符卡对照文档。
- 加入左右球拍反弹的烈焰乒乓球和余烬种植格；EX+ 增加历史档案、双侧击球和复燃追击。预警、暂停、重开与阶段清场均接入现有战斗流程。
- 敌人池排除气球、矿工和远程攻击僵尸，保留近战单位与月兔。
