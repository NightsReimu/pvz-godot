# v1.0.164 古代庭院与天气融合改进

第八世界的庭院背景重新制作，加入四种天气，修复“雨中种植物”等小游戏无法融合的问题，并扩展古代材料的弹药与融合大招。

- **庭院背景**：重画山景、缓慢流动的云层、寺院与鸟居周围的边框、青石路和草地细节。石径与草地使用可复现生成的原创 SVG 纹理并缓存加载；布局适应桌面与手机棋盘。雨、雪、沙尘与虹光都有独立表现，天气切换渐变保留。
- **十种天气**：在晴天、烈日、细雨、雷暴、东风、大雾之外增加飘雪、冰雹、沙尘、虹光。飘雪使僵尸移速降低25%、冰系伤害增加25%、火焰降低15%；冰雹使移速降低15%，每轮为至多12名敌人造成28伤害；沙尘使直射视野缩到3.5格并降低僵尸移速10%；虹光使植物产阳、出手与点击大招充能提高15%。8-1至8-5分别安排不同天气组合。
- **天气覆盖普通单位**：普通冰系子弹、融合冰雷载荷、抛射、蒲公英孢子、保龄球弹丸与火爆辣椒直接火焰均进入天气判断；雷暴出手加速识别融合里的任意电系材料，烈日的铁甲迟缓也作用于其他金属护具。关卡有天气日程即可启用，退出后不会带入下一局。
- **小游戏融合**：雨中落种可免费叠种到已有植物形成融合，也可用融合工具合成两株场上植物；排山倒海的一张卡会种植或融合整列合法地格。隐形僵尸中的融合路灯继续照明，融合星星果继续点亮星位，无草皮之地能识别融合攻击植物。三消继续使用交换操作，传送门核心不能作融合材料或被覆盖。
- **雨中天气**：小游戏的细雨与雷暴使用共同天气系统，普通火焰减弱、雷电增强，落雷优先寻找铁甲；手机天气条放在种子栏的空位，避免挡住按钮。
- **茶蚀与奶浪弹药**：茉莉花茶可给其他材料的子弹附加3秒虚弱，使目标承伤增加30%；金铲铲牛奶附加轻量击退，首领与魅惑友军不被击退，同一目标有0.8秒击退间隔。电眼菜问、等离子菇、链莲与脉冲球等材料加入雷电载荷。40种基础弹型可组合八类载荷，共10,240个登记变体，保留原子弹的飞行、分裂与返回行为。茶瓣与奶浪有独立拖尾。
- **融合大招**：蒲公英保留原种全场孢子释放，电眼菜问保留雷拳与落雷；近战、光束等持续武器也能在起手后跟进两轮齐射，间隔0.45秒。一次性爆舱只在起手触发，图鉴同步说明。

验证记录见同日实现计划：147个回归入口（133个Godot脚本与14个Python脚本）；额外检查十种天气与手机布局截图、小游戏截图、Godot导入和Web导出。Windows、macOS、Web、Android通过既有发布工作流构建，网页试玩同步更新。
