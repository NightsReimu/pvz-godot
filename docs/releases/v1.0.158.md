# v1.0.158 — 植物融合与多阶进化

新增完整的植物融合系统：全部 146 种可选原种都有同种融合与后续进化，提供 362 种新植物和 364 条对称配方。

- 经典链：向日葵 + 向日葵 → 双头向日葵，继续喂向日葵 → 三辉向日葵；两个双头 → 日冠向日葵。豌豆 + 豌豆 → 已有双发；两个双发 → 机枪；继续喂双发 → 重炮机枪花。
- 跨种配方包括日光豌豆、蒸汽豌豆、冰焰回旋莲、豌豆堡垒、坚城玉米炮、磁屑投手、磁轨黑曜炮、潮雷莲炮、梦蝶孢子菇、冰瓜投手、生命荆棘堡、辉灯伞树、日晷花、虹晶激光兰、凤龙果树、烈焰芒果、极光镜阵和火山温室莲。36 条跨种路线各有继续进化的配方。
- 三种操作：把配方种子叠种到场上植物；点「融合」后依次点两株场上植物；点「融合」后依次点两张种子，准备融合种子再种植。最后一种让樱桃炸弹、辣椒、咖啡豆、圣光花等瞬发或附着原种也能形成持续作战的融合植物。
- 叠种支付新增种子的阳光并进入冷却；两株场上合成消耗供体。种子预融合在成功种下时支付两份种子费用并冷却，传送带必须有两张实际卡片。取消、阳光不足、冷却、地形错误或配方不成立都不会扣资源或丢失植物。
- 新植物使用 362 个独立 SVG 模型，包含多头、炮膛、菌盖、树枝、竹节、藤蔓、花冠、果实、护甲与元素结构；武器朝向保持向右。种植预览、场上单位与图鉴共用模型，加入合成盛放、元素弹丸、回旋拖尾、光束、护庭光环和大招动画。
- 普攻和点击/能量豆大招按形态及成分获得齐射、抛射、贯穿、溅射、缓速、灼烧、毒蚀、震晕、缠根、梦蝶魅惑、金属回收、阳光、治疗、护盾、显形、幽灵援军或岩浆冷却等能力。三姐妹 Boss 的三个身体均可被融合植物索敌；面积伤害按共享本体去重。
- 保留伤势比例、外层护甲、冷却与已使用的复活次数；被控制或施放大招的植物不能借融合解除状态。睡莲、花盆、木塞融合保留底座层与地形规则，已有上层植物不会被覆盖。咖啡唤醒、南瓜护甲和原有小游戏操作继续保留。
- 图鉴展示材料、特性、大招与下一阶配方。融合植物由配方取得，不进入普通种子选择、抽奖和碎片池；旧存档可直接继续。
- Windows、macOS、Web、Android 版本同步为 `1.0.158`，Android 版本号 `10158`。

操作提示：配方有限，任意两株不保证能融合；终阶不会无限叠加。可从图鉴查看当前已获得原种能够解锁的融合结果。

验证：138 个自动测试入口；新增融合回归覆盖全部原种的实际预融合与种植、全部新植物的普通攻击和能量豆、经典升级、继续融合、消耗与失败原子性、地形与底座、控制状态、抛射落点、冰火状态、分层护具、友军过滤和三姐妹索敌。原生截图检查包含 362 个模型、桌面与手机战场、预融合、图鉴和大招，绘制不修改战斗数据或随机数。

开发重建素材：先运行 `godot --headless --path . --script scripts/tools/export_fusion_plant_art.gd`，再运行 `python3 scripts/tools/build_fusion_plant_art.py`，最后重新导入项目。
