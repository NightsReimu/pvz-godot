# v1.0.140 — 投手朝向修正

修正 7 种投手的视觉朝向：脸朝右侧来敌方向，装载弹药的投臂位于左后方。

- 涉及卷心菜投手、玉米投手、西瓜投手、天窗瓜炮、龙泡泡投手、喷气冬瓜和剧毒口香糖投手。
- 选卡、图鉴、种植预览与实战共用修正后的 SVG，生成脚本同步修复。
- 普通射手朝右，裂荚射手保留前后双向结构；攻击方向、弹道、伤害和数值保持既有规则。
- 包含 v1.0.139 的图鉴具体数值与大招说明更新。

验证：166 个植物 SVG 的加载与裁切检查、全部 146 种植物和 129 种僵尸/Boss 的渲染入口、轮廓/状态/动作视觉回归、图鉴说明测试，以及发布配置检查。已复查桌面与手机尺寸的投手朝向。
