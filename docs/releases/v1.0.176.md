# v1.0.176 风神录终末弹幕强化

4-19 秋穰子与 4-20 键山雏的完整终末增加实际弹幕数量，让融合阵地承受持续、多行的火力压力。

- **实际出弹增加**：与 v175 的逐招真实发射对照相比，两关四档难度的总发弹率提高到约 **2.05–2.31 倍**。同时修正完整终末已指定下次齐射时间后又额外等待的问题，保留原有难度递进。
- **稀疏机制卡补齐火力**：催熟田垄、贡仓、迟发厄印、厄偶与失准卡加入交替三行齐射，实测每秒约 4.71–10.59 发；旋转针弹、钟婆火焰、痛苦之流与流放人偶保留原本环形轨迹，并间歇补充另一行的弹幕。v175 的新增终末招式也应用完整形态的弹量提升。
- **横屏弹幕真正到达阵地**：修复六行棋盘在宽而矮的窗口下，横向弹速受格子高度拖慢、在到达中后场植物前就消失的问题。曲线转向、解冻与再瞄准同步使用格子尺度；手机横屏与桌面布局都能实际命中中后场。
- **反制与性能**：保留至少一秒的无伤预警、镜返、时停、大招反制和阶段清理。实际发射与空场压力测试均无达到 480 子弹／72 光束上限而丢弹的情况。
- **维持既有平衡边界**：沿用 v175 的符卡列表、阶段生命、单发伤害、传送带补牌与终末僵尸增援节奏；秋静叶及键山雏的弱化道中、其他东方角色的弹幕行为保持一致。

验证包括 86 条实际出招的旧版对照、30 位其他角色控制样本、380 次不同棋盘／窗口的中后场碰撞验证，以及 4-19／4-20 的四档完整原生战斗。旧版固定策略七胜一败：秋穰子 Lunatic 被僵尸突破，键山雏 Lunatic 通关但损失明显增加。秋穰子另用真实购买的樱桃、仙人掌和三叶草应急，通过全部 8 阶段，耗时 1056.5 秒、未消耗小推车；不使用免费植物、额外阳光或强制大招。38 项受影响回归通过，并检查桌面与手机横屏原生截图。
