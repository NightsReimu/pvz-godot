# v1.0.178 东方 Boss 双倍伤害与符卡减伤

所有东方 Boss 的实际攻击伤害较 v1.0.177 **提高 100%（×2）**，正式符卡展开期间获得 **75% 伤害减免**。

- **完整角色覆盖**：覆盖 34 位东方角色，包含因幡帝及最新河城荷取；Easy／Normal／Hard／Lunatic 和 EX／EX+ 均保留原有难度、角色及阶段差异，再应用一次双倍来源倍率。
- **实际攻击翻倍**：子弹、激光、直接技能、专属召唤攻击与敌方近战都使用明确的 Boss 来源。补齐厄运、永琳／辉夜特殊伤害、魔理沙光照、慧音技能、蕾米莉亚吸血、妖梦怨灵与魅惑植物等独立路径；普通增援、普通僵尸及背景地形伤害保持原值。
- **正式卡施放期间减伤**：已宣告且仍在展开的原作、原创符卡只承受 25% 伤害，弱化道中和完整终末采用同一规则。非符、待机、蓄力、收招、过期或缺失卡片不触发新减伤；原有耐久无敌与复活、后继流程继续保留。
- **统一受伤入口**：普通弹丸、灰烬、融合大招、反射、穿甲都遵守符卡保护。修复樱桃、土豆雷、毁灭菇、11 种直接扣血大招、原生大嘴花与藤鞭的旁路；普通僵尸保持原有身体伤害和吞噬行为。小推车对每个东方 Boss 只结算一次，按固定伤害遵守减伤和阶段门，普通僵尸仍能正常清除。
- **状态可见**：正式符卡血条显示“展开 · 减伤75%”，难度选择显示新的 Boss 伤害倍率与符卡减伤规则；非符和耐久牌保留相应状态。

验证包含 v177 的 54 组真实 HP／护甲伤害对照、864 项来源系数，以及全部 102 个关卡难度变体的卡片身份、顺序、生命和生命周期对照。实际攻击准确翻倍且不重复乘算；普通攻击与环境对照不变。灰烬、直接扣血、吞噬、镜返、持续伤害、阶段门、时停、复活与清理另有真实伤害回归，桌面与手机横屏状态显示已检查。

50 项受影响回归通过。实际空场、正常卡片／阳光与赚取的大招流程中，4-19、4-20、4-21 的 Easy 分别在 643.75／726.10／766.50 秒通关，均未消耗小推车。旧固定阵地策略在 4-20 Lunatic 第 1／9 阶段被击穿；最高难度防守压力明显增加，该失败保留为策略证据，伤害倍率没有下调。
