# v1.0.179 · 九天瀑布与要塞之山

新增东方 4-22，参考《东方风神录》四面：六行全水的瀑布长道中，犬走椛守关，射命丸文终末登场后转为六行山腰旱地。道中按实际时间出怪，约 120 秒遇到弱化犬走椛，终末不会早于 300 秒到场；击破道中后仍有大量水兵、毛玉、精灵与融合敌人。Easy / Normal / Hard 使用慢传送带，Lunatic 自选卡。

犬走椛保留原作非符的巡山扇弹与交错剑阵，并加入千里眼剑盾和枫盾围阵符卡。射命丸文原作岐符、风神、耐久与塞符按四档变化，终末分别有 6 / 8 / 9 / 10 个阶段；Normal 以上的「幻想风靡」、Lunatic 的「无双风神」是塞符之前的耐久阶段，结束后继续战斗。

射命丸文在各张符卡和收招期间持续在六行、前后各列高速飞行，留下有限残影，本体、命中点与弹幕发射点同步移动。追加逆风苗圃、融合花圃取材、落叶回廊、山腰风栅、天狗增援与残影接力符卡。普通和融合植物都会受风压影响；伞叶、显形植物、扎根防御及本行大招提供反制，终末持续有融合僵尸增援。活动龙卷风能实际卷走直射、投射、追踪、回旋及莲华实体弹，包括融合弹丸；被卷走的子弹绕风旋转后散去，能量豆与本行大招提供反制。场景转换时全部睡莲消失，上层植物保留身份、生命、融合状态和大招充能；已有水生植物适应旱地，游泳敌人继续存活，之后的水路卡片换为适合旱地的选择并继承冷却。

接入用户提供的两组各 24 帧素材与道中、终末两首 BGM，保留完整剑光、盾、尾巴、团扇和枫叶。终末音乐只在射命丸文真正登场时播放。桌面和手机横屏均有独立侧景，瀑布缓缓转为山路、鸟居与枫树；无浓雾遮挡。

风神录六位 Boss 另外加强：在本轮通用提升之上，实际伤害再乘 2.5；秋穰子、荷取及其余四位分别采用 2.25 / 2.5 / 1.75 倍的弹幕密度，出弹间隔乘 0.78。手写洪水、弹墙、光学折线也计入密度，修正手机六行道中弹幕难以到达植物的问题；道中血量和阶段仍保持弱化。

本版同时发布上一轮已提交的平衡、融合和性能改进：

- 东方 Boss 伤害较 v1.0.178 再提高 150%，正式符卡减伤提高到 87.5%；游戏内追加符卡统一标为“符卡”。
- 修复射手融合大招的即时原生齐射与持续强化，改善双生的输出、耐久和支援，并更新 296 个双器官模型。已有双倍产阳规则保持稳定，纯灰烬双生恢复原生引信首爆。
- 剔除开发资源，按场景预热并限制近期纹理、音乐缓存；优化密集子弹的格子扫描与实时目标查询，修复同帧连续命中尸体。此前同条件本地 PCK 减少约 12%，启动纹理内存减少约 92%；本轮新关卡素材另计。

验证覆盖四档真实流程、长道中门槛、水路种植、实际场景转换、耐久推进、原生伤害与减伤、持续增援、反制、暂停、重试、缓存和碰撞回归，以及原生导出包中的人物、场景、音乐与桌面/手机画面。
