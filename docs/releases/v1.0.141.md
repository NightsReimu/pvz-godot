# v1.0.141 — 植物独立 SVG 形态更新

这次更新集中处理植物素材“共用同一底膜、只换颜色”的问题。

- 重建全部 144 个植物物种及 22 个状态变体，共 166 个 SVG 文件。
- 生成器保留低层路径、渐变、叶片、花瓣、晶体和面部工具，但完整主体会按物种和玩法类别生成独立基座。
- 水生植物加入水面和叶脉，蘑菇加入菌丝/菌环，果实加入果托和分瓣，树/竹/藤加入根系，炮台/投手加入支架和弹仓，坚果加入不同壳体结构。
- 为海蘑菇、阳光菇、虚空菇、冥界菇、混沌菇、砖墙坚果、高坚果、天窗瓜炮、喷气冬瓜、浮石墙、坚果、豌豆射手和琥珀射手补充了会改变轮廓的专属器官。
- 状态文件名和运行时加载接口保持不变；坚果裂纹、土豆雷未布雷、蘑菇成长/躲藏、食人花咀嚼等状态继续沿用原有主体。
- 向量资源测试新增主 SVG 唯一签名和采样轮廓检查，避免后续回退到同形换色。

验证：`vector_art_assets_test.gd` 检查 144 个物种、166 个 SVG、144 个唯一签名和 144 个唯一采样轮廓；`game_boot_test.gd`、`ui_surface_polish_test.gd`、`plant_effect_alignment_test.gd` 均通过。显示像素测试在当前无窗口的 headless 环境中按测试约定跳过。
