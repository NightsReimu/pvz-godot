# v1.0.168 伊吹萃香 · 萃梦终末酒宴

新增古代世界 8-6 东方关卡，通关 8-5 后解锁。萃香使用本作东方 Boss 的分阶段血条、非符与符卡宣言，战斗期间继续生成普通僵尸增援。

- **四种难度**：Easy / Normal / Hard 传送带，Lunatic 自选卡，分别为 7 / 8 / 9 / 10 阶段。道中是只有弱化非符的萃香，退场后继续敌群波次；终末以新的满血本体登场，切换本次提供的终末 BGM。
- **六张《东方萃梦想》故事符卡**：按原名与顺序展开「投掷的天岩户」「坤轴的大鬼」「追傩返黑洞」「超高密度磷祸术」「六里雾中」，始终以「百万鬼夜行」收束。投石、巨大化、密度核、鬼火分裂、化雾与实体小鬼分别对应不同战斗表现，爆发伤害不能跳过后续必需符卡。
- **四张原创符逐档累积**：伊吹瓢变大倾倒的「青石酒河」、收普通豌豆再释放鬼火的可破坏「萃豆酒仓」、释放方圆三角弹型的「分酒席」、多行酒液配合实体小鬼的「百鬼席」。原创符名均明确标注，机制结合疏密操纵与植物阵地。
- **酒河有真实反制**：金色行预警后，酒浪从右向左推进，使本行植物行动速率降至 55%。普通、融合与底层植物都受影响；茶与牛奶保护附近植物，植物正常充能的大招或能量豆清除本行。酒仓最多吸收八颗普通豌豆，提前打碎可取消反击；大招、融合特殊弹、火弹与投掷弹不被吸收。
- **庭院夜宴与素材**：青石棋盘、紫色月夜、庭院灯火、倾壶酒流、岩击落点、聚密光环、鬼火与雾气。直接接入用户提供的 24 姿态透明角色图及原始 MP3，来源与 SHA-256 记录见 `art/source_sheets/suika/README.md`。桌面与手机均使用正确的当前段血量与符卡进度。
