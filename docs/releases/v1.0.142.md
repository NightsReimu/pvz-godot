# v1.0.142 — 经典植物形态修正

本版本修正经典 PVZ 植物的 SVG 识别度：

- 坟墓吞噬者使用独立的绿色低矮捕墓轮廓，不再复用食人花主体。
- 魅惑菇使用明显紫色渐变、催眠旋纹和紫色菌盖。
- 双发射手保持双豌豆头，豌豆射手与樱花射手保持单头结构。
- 金盏花采用橙色花瓣和金色花心，与向日葵明确区分。
- 南瓜恢复宽厚的带肋瓜体，海蘑菇使用蓝绿色水生菌盖。
- 向量资源回归新增经典植物契约检查，锁定关键轮廓和配色。

验证：`vector_art_assets_test.gd`（144 个物种、166 个 SVG、144 个唯一签名、144 个唯一轮廓）；`game_boot_test.gd`、`ui_surface_polish_test.gd`、`plant_effect_alignment_test.gd` 均通过。`unit_identity_visual_test.gd` 在无窗口 headless 环境按约定跳过像素对比。
