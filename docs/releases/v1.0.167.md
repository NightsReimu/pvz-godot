# v1.0.167 东方古城庭院与青石棋盘

第八世界重新制作为东方古城庭院，背景与种植格一起改变。

- **古城建筑**：专用场景插画包含红柱瓦殿、灰砖宫墙、木格门、石狮、铜灯、栏杆与雕刻石阶；远处古城屋顶、山景和秋叶构成层次。背景按棋盘边界分区适配，顶部留出建筑展示带，让殿门与院墙在实战中可见。
- **45格青石棋盘**：独立绘制云纹青石种植台，三种石材细节交错排列，带倒角、石纹、裂纹、铜色角饰、凹槽接缝和少量苔痕。格子与实际种植坐标一致，调整窗口后保留植物。
- **天气融入地面**：雨中石板变暗并泛起反光、水纹；雪与冰雹在石台边缘积雪。原有十种天气的切换与战斗效果继续生效。
- **入口同步**：主页缩略图、第八世界封面、简介和选卡地形预览同步为古城庭院，预览共用实战青石贴图；卡片保留透明圆角。桌面与手机分别预留建筑与操作空间。

背景由内置 imagegen 生成，石板 SVG 由可复现的绘图脚本生成；生成提示及来源见 `art/ancient/README.md`。

验证：16项相关 Godot 回归通过，覆盖第八世界、天气与融合、气球小推车、小游戏融合、布局、手机点选、世界导航和启动；README、发布工作流与 Android 导出配置3项 Python 检查通过。已检查1600×900、1365×768、844×390的晴天、雨雪及菜单原生截图，Godot 导入无脚本错误。
