# v1.0.162 原生融合与组合弹药

修复投手落点落在移动僵尸身后，以及融合植物使用通用攻击后丢失原材料特性的问题。

- **材料独立运作**：144 种可融合材料逐项对照。持续攻击和支援调用原植物的行为，每种材料保存自己的装填、蓄力、成熟和其他状态；灰烬材料保留独立的长冷却爆发，爆炸伤害不会进入普通连发弹。再次融合保留已有冷却。
- **投掷与选敌**：投掷弹绑定原目标并更新落点，月炉保持跨行选敌和追踪；目标死亡、隐藏或转为友军后停止追踪。莲矛保留环射，提灯保留对空，镜芦苇保留远程攻击和 Boss 弹幕反弹。玉米加农炮融合后仍可手动瞄准，保留二十秒装填。
- **组合弹药**：玉米粒与黄油分别保留弹体及黄油定身；火炬可点燃它们和其他弹种，低帧率跨过火炬也能触发。火焰、寒霜、毒蚀、雷电、梦蝶和缠根可以组合；樱花分裂与棱晶碎片继承载荷。组合玉米、黄油、卷心菜、花瓣、晶体和流星有对应造型，元素尾迹随时间变化。
- **魔术花弹池**：覆盖 40 种基础弹型，包括投掷弹、滚动果轮、环弹、回旋、追踪、分裂和火山植物弹药；加上六类元素的组合，共 2,560 个登记变体。多元素随机弹降低出现权重。
- **被动与大招**：补正高坚果挡跳、信号藤盾、提灯显形、反伤、地热响应等对融合材料的识别；南瓜护甲破损不会直接删除仍存活的融合植物。大招发动先恢复满生命，补正胆小菇、激光、地刺、玉米加农炮等融合大招的实际作用。
- **底座退出融合**：花盆和睡莲保留正常种植与承载功能，不能作为融合材料。清理相关配方和 297 个旧形态，保留 10,624 个固定独立 SVG；其他材料仍可两两融合并继续共生，融合植物不进入图鉴。

验证：144/144 个回归入口通过。新增原生与融合材料的 45 秒行为对照、移动目标命中、环射/追踪/对空/反弹、组合黄油、手动炮装填继承、分裂载荷、友军保护、底座排除及大招满血检查。检查 2,560 个魔术弹变体的生成和伤害倍率，并推进各基础弹型的实际运行。10,624 个模型通过已有 SVG 与几何唯一性检查；完成 1600×900、844×390 原生战场及组合弹药动效截图核对。

Windows、macOS、Web、Android 四平台发行；网页试玩同步更新。
