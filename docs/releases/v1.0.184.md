# v1.0.184 · 风神录符卡还原与演出美化

4-19 至 4-23 的风神录 Boss 按原作重做了符卡的弹幕结构，并针对本作的六行草坪做了改编；符卡编号与名称不变。

**秋静叶 / 秋穰子（4-19）**
- 静叶的非符：第一发精确瞄准，之后炮台限速追踪（原作的偶数弹）；「狂乱的落叶」改为整片草坪飘落的红叶。
- 「秋之天空」：上下两个弹源反向摆动、持续交叉；「秋之天空与少女之心」交替长短米粒列，长列中混着柿子中弹。
- 「大年收获者」「谷物神的允诺」：先出金色预告线，再发射整行收获激光，米粒从上方落下；Lunatic 增加逐列逼近的红色竖激光。

**键山雏（4-20）**
- 「厄神大人的生理节律」：两条反向螺旋，弹速随节律起伏。
- 「破裂的护符」「损坏的护符」：成团护符从两个角落交叉射入，Hard 以上会在飞行中裂成米粒。
- 「厄运之轮」「大钟婆之火」：2～4 条 winder 组成摇摆的轮辐（E/N 针弹，H/L 火弹）。
- 「流放人偶」：随着时间推移，追加会转向植物的病毒弹。

**河城荷取（4-21）**
- 「妖怪黄瓜」「延展手臂」：两侧机械臂各发一道激光，交汇在被瞄准的植物上。
- 「河口浪潮」「山洪暴发」「幻想大瀑布」：倾斜的光弹前锋（潮涌）同时跨越多行。
- 洪水系符卡：加入自机狙奇数弹，Hard 以上的泥浆会摆动前进。

**犬走椛 / 射命丸文（4-22）**
- 文按阶段使用三种非符，其中包括顺逆两层“甜甜圈环”。
- 「天之八衢」「猿田彦神之岔路」：先在草坪上铺开道路网，羽弹随后在不同时刻依次坠落。
- 「风神木叶隐身术」：两层反向叶环，约 20 方向（Easy）或 28 方向。天狗颪与二百十日则更散乱、更快。
- 塞符：固定的鳞弹列，加上随机角度的米弹环。

**东风谷早苗（4-23）**
- 客星系：两侧激光交叉扫过各行，Hard/Lunatic 反向扫描并在边缘反射。
- 开海：弹墙随时间变长，Hard 以上从上方加入下落弹。
- 星之仪式：红星五芒星先停住再散开，蓝星成墙推进。
- 神之风：约 34 方向的环，加约 16 方向的自机狙。

**演出**：新的子弹造型（红叶、米粒、柿子、护符、针、火弹、人偶、病毒弹、光弹、珍珠、羽毛、鳞弹、星、海之枪等）。激光带预告线和起点光团。雏、椛、文、早苗新增宣言主题，各 Boss 的施法封印改为主题魔法阵。正式符卡期间，Boss 脚下展开魔法阵，身后有光晕和主题粒子；隐身中的荷取和文不会因此暴露位置。所有弹幕仍保留至少 1 秒的无害预警。

**本作改编 · 坚果挡激光**：原作激光会贯穿，这里也会伤害沿线的植物，但遇到第一株坚果墙、高坚果、南瓜头（含其融合）时会击中它并停下，前排坚果依然能保护后方阵型。

**平衡**：每张卡的伤害压力都按改动前校准（183 个卡/难度组合的中位比值为 1.00）。用真实融合阵容跑完整关卡（空场开局、真实材料与自然充能）：v1.0.183 为 20 胜 2 负，另有 1 局到时限未结束；本次为 21 胜 2 负。
