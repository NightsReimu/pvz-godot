# v1.0.144 — 战斗弹丸与特效 SVG 美化

本版本为战斗中的弹丸和命中特效加入一套独立创作的 SVG 视觉资源：

- 32 种弹丸 SVG 覆盖现有 image2 弹丸，并补充龙泡泡、剧毒口香糖、鳄鱼能量球、寒冰豌豆、火焰豌豆和凤凰火焰。
- 76 种特效 SVG 覆盖现有命中、法阵、光束、爆发、天气和 Boss 符卡特效。
- 每个资源使用独立轮廓、渐变、描边和稳定签名，不再依赖同一张底图换色。
- 新 SVG 只负责视觉层，保留原有弹道、碰撞、伤害、动态拖尾和程序化兜底；资源加载失败时不会中断战斗。
- 加入运行时纹理缓存，降低弹幕密集时的重复资源加载。

验证：`combat_vector_assets_test.gd` 通过（0 failure）；并运行 Godot 编辑器导入检查与 `git diff --check`。
