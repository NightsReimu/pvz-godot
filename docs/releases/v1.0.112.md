# v1.0.112 庭院小游戏

主页底部新增「庭院小游戏」入口，七项挑战直接开放，关卡提供所需植物卡片。每项首次通关奖励 200 金币并记录通关标记。

- **雨中种植物**：暴雨泳池里点击落种收入卡槽，免费种植；种子会过期，开局攻击植物和周期睡莲保证供给。
- **宝石连连看**：相邻植物交换三消，植物仍会攻击僵尸；支持交换动画、连锁补种、无效交换回退、提示与无解恢复，消除 50 组通关。
- **隐形僵尸**：观察脚印布防；受击、冰冻、控制和附近路灯使敌人现形，隐形不会影响植物索敌。
- **星星果**：在全部 14 个金色星位同时种下星星果，完成星图。
- **无草皮之地**：花盆重建石地种植位，初始 5000 阳光，无天降阳光。五轮防守之间补给 250 阳光，可整备后手动出击；整备时铲除按剩余血量退款。
- **保护传送门**：同时守住两座核心，入口定期预警换路，把僵尸传送到核心前方；核心被毁即失败。
- **排山倒海**：屋顶传送带，一张卡填满整列的可种植空位；先放花盆，已有植物保留，无有效空位时不消耗卡片。

战斗底部提供目标进度和「玩法」说明，查看说明会暂停战斗；支持暂停、重开和返回小游戏。修复暴雨背景在手机窄屏下的多边形绘制错误，并减少落种重叠。

验证：七模式规则、完整换波、合法三消达成目标、索敌、核心失败、一次扣卡、存档标记与奖励去重测试；1600×900 与 844×390 原生战斗截图和触控入口检查；现有无尽/每日、地图导航、传送带、暂停、HUD、挑战目标和治愈葫芦回归检查通过。
