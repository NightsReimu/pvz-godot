# v1.0.160 融合特性与战斗重构

修复灰烬材料融合后将一次性爆炸伤害叠进快速连发子弹的问题。融合现在按原材料分别运行射击、投掷、回旋、光束、近战和蓄力武器；各自保留周期、射程与特殊作用。

- **灰烬与重武器重新平衡**：樱桃爆舱 990 伤害 / 32 秒 / 155 范围，毁灭菇爆舱 1260 伤害 / 48 秒 / 220 范围；火爆辣椒为整行火焰，土豆雷为近身范围爆炸，倭瓜、海带与大嘴花为近身单体重击。这些为基础融合通道数值，重复材料与多武器组合按递减规则调整。爆舱初次融合需要充能，加速无法缩短爆舱周期；继续融合继承剩余充能，大招只释放一次爆舱，随后重新装填。
- **保留实际武器类别**：卷心菜、玉米、西瓜、天窗瓜炮、黑曜蓟、硫磺豆、蓄压竹等保留真实抛物线。玉米加农炮保留至少 20 秒装填，高伤害武器使用更长周期。直射与投掷材料共生时分别开火，不再由单一攻击类别覆盖其他材料。
- **保留特殊能力**：镜芦苇继续融合后也能拦截敌方狙击和反弹 Boss 弹幕；新大招“镜面折返”反转场上敌方弹幕，并给邻株短时镜盾。保留伞叶空袭拦截、凤凰复生、阳光光环、背向射击、蓄压竹空闲存弹、黄油冻结、硫磺易伤、分裂弹、荧光藤二次爆发、喷气蒸汽和盐沼效果；冰晶女王保留范围脉冲，寒霜柏保留累计停留冻结。镜像蘑菇不能把一次性爆炸复制为持续光束。
- **优化建模与动画**：更新全部 10,921 个固定融合 SVG，并同步递归共生模型。按武器加入连接茎干的投掷勺臂、爆舱、毁灭菌盖、镜面瓣、蓄压仓与伞盖；射口保持朝右，双向射手保留其背向射口。战场增加真实装填进度、爆弹落点提示、圆形冲击波、整行火焰与镜面反射动画。
- **图鉴说明更准确**：分别列出每个武器的伤害、周期与范围类型，并说明被动继承及爆舱充能规则；继续支持分页查看全部大招。

验证：141/141 个完整游戏回归入口通过；全目录 10,921 个固定融合形态的攻击、大招、友军安全与 SVG 渲染通过。新增真实弹道、爆炸落点范围、持续火力与爆舱隔离、重炮周期、递归充能、狙击/弹幕反弹、蓄压存弹、冻结与特殊弹药验证；另完成 60 帧大招运行模拟及 1600×900 / 844×390 原生截图核对。

发布：Windows、macOS、Web、Android 四个平台，网页试玩同步更新。
