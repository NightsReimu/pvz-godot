# v1.0.173 僵尸与东方 Boss 增强、融合大招起手重击

融合植物、能量豆和大招叠加后，战斗明显偏向植物：普通僵尸啃完一株豌豆要 12 秒以上，东方 Boss 弹幕在 Easy 只造成一半伤害。本版加强僵尸与东方 Boss，并让每个融合大招点下去都有立刻可见的效果。

- **融合大招起手重击**：每个战斗型融合大招先打一次起手重击，伤害约为该融合 7 秒的持续火力，下限 180、上限 1100，三种以上材料再提高。范围随招式：
  - 齐射、回旋、光束、冲阵打前方三行；
  - 投手与星阵打最靠近房子的 6 个敌人；
  - 带爆舱的爆田以爆舱本身为重击，爆炸范围内无敌人时炸向本行附近最近的敌人，仍保持 v1.0.170 设定的 15% 爆炸加成上限；
  - 吞噬重咬身边最强的两个敌人；
  - 领域附带定身 3 秒，城垒附带震退与 1 秒眩晕。
  
  此前约三分之一的融合因原生武器射程短、爆舱够不到敌人，点下大招后几乎没有效果。抽样 300 种融合，大招 3 秒内的额外伤害中位数从约 400 提高到约 1500。灌注技能的伤害下限同步提高到起手重击的 35%。丰收与花园等资源型大招保持产阳光、治疗与加速。
- **僵尸增强**：所有非 Boss 僵尸生命 ×1.25、啃食伤害 ×1.8、移速 ×1.08；古代武士保持指定的 2100 耐久。普通僵尸变为 250 生命、每秒啃食约 43，啃完一株豌豆约需 7 秒（此前约 12.5 秒，原作约 3 秒）。东方与普通关卡的增援僵尸同样受影响。
- **融合僵尸进入冒险**：此前融合僵尸只在无尽模式出现。现在第二世界起，每波有一部分僵尸带着融合装备登场：第二世界约 10%、只有路障类，此后逐世界提高到约 25%，并逐步开放铁桶、铁门、橄榄球与暗黑头盔，困难模式再加 8%。每关的替换序列固定，重开相同。
- **更多融合僵尸**：新增「砖块」头盔（1400 耐久，非金属，磁力菇吸不走）和「武士盔」（1050 耐久，金属，带金色角饰）。古代法师与军师也能戴头盔。融合僵尸从 163 种增加到 289 种，新头盔都有独立造型。
- **图鉴**：融合僵尸与融合植物一样不再列入图鉴，只在战斗中出现。
- **东方 Boss 增强**：弹幕与技能对植物的伤害倍率提高到 Easy 0.66、Normal 0.78、Hard 0.84、Lunatic 1.10、EX 0.68、EX+ 1.05，原为 0.50 / 0.60 / 0.72 / 0.86 / 0.50 / 0.82。除 Hard 外，各难度出招间隔缩短约 10%、弹幕密度提高 6%、Boss 生命提高 15%；增援僵尸也随僵尸增强变强。Hard 只提高伤害并略加快出招，因为萃香 Hard 是全游戏最长的一场（9 个阶段且不补种），按其他难度的幅度增强时，完整防线会在第 6–7 阶段耗尽。现在完整防线打完萃香 Hard 约需 385 秒，打完秋穰子 Hard 约需 242 秒。道中与终末的相对强弱保持 v1.0.170 的设定。
- **修复**：部分子弹缺少减速字段时的运行时报错；秋静叶与秋穰子的立绘帧改为按素材声明的动作选择，行走、阶段与终末姿态正确，秋穰子受击改用退缩帧，倒地帧只用于击败。

验证：完整回归通过，新增融合大招起手重击、僵尸平衡、冒险融合僵尸与图鉴的回归检查；已对 300 种融合测量大招效果。Windows、macOS、Web、Android 通过既有发布工作流构建，网页试玩同步更新。
