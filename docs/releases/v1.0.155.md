# v1.0.155 — 东方符卡插画特效

- 用内置图像生成工具绘制六组独立透明特效：红白封印法阵、金色星光蓄力、六角冰晶、樱花与幽蝶灵光、凤凰火焰、带眼睛和缎带的紫色隙间。保留原始 RGBA 与柔光透明度，记录提示词及源文件哈希。
- 灵梦、橙、魔理沙、芙兰朵露、琪露诺、蕾蒂、妖梦、幽幽子、妹红与八云紫的具名符卡获得对应插画。蓄力渐入、法阵展开与旋转、持续脉动、结束淡出由已有技能计时驱动；暂停和时停跟随原计时，换阶段、取消或死亡时随技能所有者清理。
- 灵梦封印格、魔理沙光符格和激光发射口、妹红余烬与涅槃灼烧格加入对应的局部纹章；紫的登场和阶段隙间、幽幽子的复活灵光与妖梦半灵效果使用对应插画点缀。
- 插画绘制在植物、僵尸、弹幕、激光与原有预警之前，限制大小、透明度和额外绘制数量。伤害、血量、弹速、密度、符卡序列与碰撞规则保持当前战斗逻辑；未匹配的技能继续使用已有特效。
- 随 Boss 帧资源提前加载插画，六组纹理共享缓存；缺少纹理时保留已有渲染。
- 修正一项早期来源回归测试，使其覆盖已经更新的妖妖梦八位 Boss，并检查归档原图的实际 SHA-256。
- Windows、macOS、Web 与 Android 版本同步为 `1.0.155`，Android 版本号 `10155`。

验证：六组 PNG 原始文件与 Godot 导入透明度哈希一致；132 张符卡的视觉计时、非符排除、缓存预热、失效清理及不修改战斗数据检查通过。桌面 1600×900 和手机横屏 844×390 原生截图覆盖六类技能的蓄力、展开与持续阶段；23 项 Godot 符卡、碰撞、难度、Boss 流程、动画、预热、暂停、界面与启动回归，以及素材裁切、生成来源与发布流程检查通过。
