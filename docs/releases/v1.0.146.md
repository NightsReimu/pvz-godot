# v1.0.146 — 非东方关卡困难模式

- 所有非东方主线关卡新增“困难”难度，首次进入关卡时默认选择普通。
- 当前关卡普通通关后才解锁该关卡的困难按钮，解锁状态沿用现有普通关卡通关存档。
- 困难模式复制普通关卡的常规僵尸事件，普通僵尸数量至少提升至 2 倍；显式波次至少提升至 2 倍，短教程关也会补齐可见波次。
- 困难模式会轮换加入路障、铁桶、报纸、铁门、橄榄球、忍者和盾卫等额外敌人，同时保留原关卡 Boss 在最后阶段出现。
- 东方关卡不进入该菜单，继续使用 Easy / Normal / Hard / Lunatic / EX 既有难度系统。

验证：`level_difficulty_test.gd` 检查 167 个非东方关卡通过；`game_boot_test.gd`、`plant_effect_alignment_test.gd`、`effect_glow_test.gd`、`ui_surface_polish_test.gd`、`unit_identity_visual_test.gd`、`vector_art_assets_test.gd` 均通过。
