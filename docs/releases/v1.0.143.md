# v1.0.143 — 永夜抄动态地形种植与木塞动画

本版本适配东方永夜抄 6 面八意永琳的动态水、屋顶和岩浆格：

- 水格已有普通植物时仍可在其下补种睡莲。
- 屋顶格已有普通植物时仍可在其下补种花盆。
- 花盆现在也能直接种在普通草地，并可作为已有植物的底座。
- 岩浆格已有普通植物时可补种木塞子，封堵后不再受喷发伤害。
- 木塞子种下后保持 3 秒，最后 0.45 秒播放抬升、摇摆、缩小和淡出动画；退场只清除木塞子，保留植物和已封堵的火山岩。
- 支持层仍与普通植物分离，避免补种底座时替换顶层植物。

验证：`eirin_mechanics_test.gd`、`volcano_expansion_test.gd`、`game_boot_test.gd`、`ui_surface_polish_test.gd`、`plant_effect_alignment_test.gd`、`unit_identity_visual_test.gd`、`vector_art_assets_test.gd` 均通过；像素对比测试在无显示渲染器环境按约定跳过。
