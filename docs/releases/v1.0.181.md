# v1.0.181 · 山顶神社与风祝的奇迹

新增东方 **4-23「山顶神社的现人神」**，参考《东方风神录》五面，通关 4-22 后解锁。六行全陆地青石庭院，山顶云海、社殿、鸟居、注连绳与四御柱；晴天、东风、雨、雷暴和虹光通过已有天气系统实际影响植物、融合植物和僵尸。

道中与终末都是东风谷早苗。道中是弱化的非符与秘术星阵，终末以独立满血角色登场，沿用东方分段血条和符卡宣言。Easy / Normal / Hard / Lunatic 分别有 **7 / 8 / 9 / 10 个终末阶段**，E/N/H 使用每 2.8–4.0 秒发牌的传送带，L 使用自选卡和阳光经济。

原作客星采用迟发爆散，开海弹墙留出可观察的通道，星之仪式准备后进入神风；高难度使用相应的原作符卡名称与更密的出弹。结合本作新增青蛙使魔、短暂蛙化植物、天象苗圃、融合贡穗、御柱风蛇与六道奇迹，游戏内统一显示为“符卡”。蛙化有预警，保留植物原有生命、融合材料和自然充能，叶子保护伞、圣光庇护及本行大招可以反制；阶段结束、Boss 离场和重试会清理所属效果。

各世界普通、护甲和融合僵尸持续出现，终末战继续增援。保持风神录额外伤害 **×1.5**、正式符卡期间 **87.5% 减伤**。接入用户提供的 24 帧早苗动作及两首音乐，保留透明特效原像素；道中使用道中 BGM，完整终末登场后才切换终末 BGM。桌面与手机横屏均检查了角色、血条和天气条的位置。

四平台构建统一更新至 **Godot 4.6.3**，修复旧版 GLES 绘制批次在容量边界未正常收尾，随后出现 `Parameter "pb" is null` 和索引越界的问题。相同原生绘制复现程序在 4.6.0 崩溃、4.6.3 通过；秋姐妹关卡真实战败后的 900 次持续 GPU 绘制也无错误。该修复来自 [Godot #117725](https://github.com/godotengine/godot/pull/117725)。源码启动增加版本检查，macOS 可使用 `run-game.command`，其他平台可执行 `python3 scripts/tools/launch_game.py`；需要已安装 4.6.3 或更新版本。

验证覆盖四档阶段、出弹结构、伤害与减伤、音乐切换、真实融合资源与自然充能、天气、蛙化反制与清理、旧东方关卡、缓存，以及原生渲染和导出包。最终发弹版本的 Easy 融合路线实际通关，Normal 耐久融合路线在第三阶段失守；保留失败结果，不以强制生命、充能或通关来验证平衡。开发测试、素材源表和启动脚本继续排除在游戏发布包外。
