# v1.0.171 融合招牌大招与特效整理

融合大招不再把一串通用技能拼在一起，改为每株一个名实相符的招牌大招；同时修正大招与原种大招的特效位置、配色和遮挡，东方符卡宣言改为不遮挡植物的标签。

- **一个招牌大招**：大招由融合的主攻手法（齐射、星阵、光束、天降、回旋、冲阵、爆田、吞噬、城垒、丰收、花园、领域）加上搭档的元素灌注组成。两种材料灌注一种，三种以上最多两种；冰火合为汽爆，磁力与雷电合为磁轨，阳光与射击合为日轮。轮回、镜面、唤醒与冷泉只在需要时生效，不占用战斗灌注名额。此前大招最多同时释放七项技能，而且常见“齐射＋护庭＋丰收”的组合。
- **名字跟着搭档走**：大招名由改变招式的搭档与手法组成，例如樱桃射手「樱爆齐射」、坚果樱桃「坚壳爆田」、火炬豌豆「炬火齐射」、寒冰射手与西瓜投手的「寒霜瓜雨」。11,219 种融合从约 1,200 个拼接名变为 2,100 多个独立名，同名最多 27 种，均为同一搭档与同一手法的组合。蒸汽豌豆「汽化爆流」等命名配方恢复原定大招名，不再被拼接名覆盖。双生与三生融合使用「双生齐射」「三生丰收」等名称。
- **范围符合招式**：齐射、光束、回旋与冲阵的灌注作用于前方三行，投手与星阵作用于前方全场，爆田、吞噬、领域与城垒作用于周围3格。此前烈焰、冰封、雷电、毒雾与梦蝶都对全场生效；梦蝶不再从任意位置把全场普通僵尸魅惑。缠根仍定身全场敌人，荆棘只在近处爆发。
- **补上空缺的效果**：吞噬与领域此前只有动画，现在真正造成伤害、回复或定身。没有持续武器的火炬树桩类融合改为领域镇压。日轮贯城按说明产出阳光；爆舱仍在起手时一起引爆，图鉴说明同步改写。陨星花参与融合时带上灼烧属性。
- **大招特效**：光束扫到整行尽头，不再停在两格处；投手的陨落和爆炸画在落点，不再炸在施法植物身上。命中多个敌人时只在敌人身上显示小标记，不再重复叠画整套施法特效。领域、梦蝶、吞噬等技能使用自己的元素颜色，不再沿用植物颜色。爆舱火球更快散去，减少对周围植物的遮挡。
- **原种大招**：原种大招中 59 处大范围圆形特效从实心色盘改为扩散冲击波光环；等离子菇的「等离子风暴」改为沿三行横扫的电弧。
- **东方符卡宣言**：「符卡展开」横幅从横跨整块棋盘的深色条，改为棋盘右上角按名称宽度自适应的窄标签，第一行植物在宣言时保持可见；桌面与手机布局均已核对。
- **茉莉花茶**：腐蚀格以棋盘实际行数为界。
- **8-6 萃香酒宴**：可选植物移除向日葵和被误列为种子卡的融合「冰瓜投手」，与其他东方传送带关的规则一致；Lunatic 自选卡仍有 350 起始阳光和加快的天降阳光，西瓜投手与寒冰射手可在场上融合出带冰霜的投手。
- **萃香回归修复**：补上萃香的符卡宣言主题色；萃豆酒仓在图鉴和选卡图标中缺少实时生命值时不再报错；小小萃香在数据中声明沿用萃香本体立绘，单位身份检查据此通过。

验证：159 个回归入口全部通过（此前完整回归中由 8-6 引入的传送带规则、萃香宣言主题与单位身份三项失败已修复），新增融合招牌大招测试覆盖单一招式、命名配方原名、名称分布、汽爆合并与三行作用范围（旧版全场烈焰会失败）。已截图核对 32 种大招单独释放、全部原种植物与 80 种融合实战、45 张东方符卡画面及手机宣言布局。Windows、macOS、Web、Android 通过既有发布工作流构建，网页试玩同步更新。
