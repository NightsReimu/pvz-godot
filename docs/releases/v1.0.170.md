# v1.0.170 东方道中、终末与灰烬弹头平衡

不同角色的道中 Boss 之前直接使用完整角色血量，部分道中比终末的单段更难打。本版统一区分道中与终末，并让灰烬融合按照射击材料改变攻击方式。

- **全部东方道中弱化**：同角色预览从原基础血量的 12% 降到 9%；不同角色道中使用原基础血量的 18%，再限制为本关原终末血量的 10%。难度倍率仍生效，道中实际血量不超过新版同难度终末约 7%。覆盖全部 24 条东方路线、90 个难度组合；道中角色原有非符／符卡身份、僵尸增援与道路进度保留。
- **全部终末血量提高 45%**：在原难度血量倍率上再乘 1.45，不跳过或删减原有符卡。八云蓝战后的八云紫也正确继承难度与新版终末倍率。
- **樱桃弹头**：樱桃炸弹与直射、跨行、投手、回旋等射击材料融合时，保留原来的弹型和装填，命中产生半径 48 像素的小爆炸，不再额外投樱桃炸弹。樱桃＋豌豆直接发出带引线的红色爆炸豌豆。
- **暗爆与灼烧弹头**：毁灭菇改为半径 64 像素的紫色暗爆；辣椒改为持续灼烧弹药。投手保留抛物线，回旋与分裂弹继续使用原生轨迹。大招强化相同弹药并追击，不额外复制大型炸弹。
- **有界伤害**：单种樱桃／毁灭材料为每轮原生齐射增加 12 点弹头伤害，多头分享预算；重复材料收益递减，混合弹头总预算最多 24 点。溅射只使用弹头自己的伤害，重炮与装甲增伤不会被复制成高伤范围爆炸；同一发回旋／贯穿弹的溅射不会重复伤害同一敌人，分裂弹分摊或降低继承预算。
- **保留蓄力爆炸的组合减伤**：樱桃 990→620，毁灭菇 1260→780，辣椒 880→560，核心花 400→280，故障坚果 500→340。爆炸融合大招倍率由 1.30 降为 1.15，原充能时长保留。未融合的一次性樱桃等原种不改伤害。
- **效果与图鉴同步**：红色爆炸弹、紫色暗爆弹、引线火星、弹道火焰及小爆炸环，图鉴说明对应实际弹头／独立爆舱。护甲、隐藏目标和魅惑友军规则继续生效。

验证：46 项相关 Godot 测试与 15 项 Python 仓库检查通过。新增血量回归覆盖 90 个关卡／难度组合与 EX/EX+ 八云紫接替，新增弹药回归覆盖真实直射与抛射命中、邻近溅射、远处／友军排除、护甲、隐藏目标、递归融合、多头预算、大招及回旋重复溅射限制。四档萃香完整战斗使用正常植物伤害和充能大招，分别在 216.8 / 222.9 / 458.9 / 305.8 秒完成；Lunatic 补种仍走真实阳光、种子冷却和融合放置。桌面与移动横屏画面已检查，Godot 导入与启动无脚本错误。

发布包含 Windows、macOS、Web、Android 四平台构建，并更新在线版。
