# v1.0.166 小推车气球拦截修复

修复飞行中的气球僵尸抵达房子边界时，跳过小推车并直接导致失败的问题。

- 气球僵尸与普通僵尸共用房子边界检查：本行小推车待命时正常启动，运行时由扫过的碰撞范围清除气球，用尽后才按原规则判负。
- 草地小推车、泳池清理车和屋顶清理车均适用；小推车仍只清除所在行，保留跨帧扫过范围的碰撞判定。
- 气球启动小推车也会计入“不使用小推车”等挑战目标，运行期间不会重复计数。

本版基于 v1.0.165，保留近期融合造型与灰烬材料对空的更新。

验证：新增小推车专项回归覆盖八个场景；修复前已重现失败，修复后通过。共通过12个相关Godot回归脚本、README及发布工作流和Android导出配置三项检查，Godot 4.6编辑器导入成功。四平台安装包及网页试玩由正式版本标签构建发布。
