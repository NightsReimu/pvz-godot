# v1.0.121 镜芦苇反射与战斗回归修复

- 镜芦苇普通反射现在记录反射点、出射方向和反射年龄，弹幕会显示清晰的冰蓝尾迹、镜面高亮和出射光环。
- 镜芦苇大招「镜面折返」改为完整的镜面展开效果：全场 Boss 弹幕掉头时显示旋转镜环、放射光线和碎片扫光。
- 反弹弹幕会清除入射弹的追踪、轨道、边界跳转和角速度修饰，避免反射后路径扭曲、二次穿镜或看起来像消失。
- 镜芦苇大招保持原有伤害倍率和全场反弹规则；反射弹继续对僵尸沿路径造成一次伤害。
- 修复十六夜咲夜「Luna Clock」暂停期间错误搬运植物的问题，改为冻结战场并在标记格降下飞刀。
- 屋顶世界补回已见过的月兔、飞艇玉兔、玉兔守卫、毛玉和妖精敌人，避免后续屋顶关卡敌人池断层。
- 植物能量豆运行时改为从权威植物定义表动态覆盖新植物，新增植物不会因为忘记登记而失去运行时支持。
- 修正 Reisen 24 帧资源的透明轮廓校准，并同步 `project.godot` 与所有导出预设到 1.0.121。

验证：镜芦苇大招与反射元数据、植物反射视觉、东方弹幕碰撞、符卡契约、Boss 战斗流程、屋顶关卡、咲夜关卡、小游戏、UI 布局和移动端缩放测试通过。
