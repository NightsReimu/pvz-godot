# v1.0.111 · 永夜抄六面 B：蓬莱山辉夜

新增 **3-24-b「五道难题」**，通关 3-23 后可进入，与 3-24-a 共用永琳道中、传送带卡池、回廊背景和道中音乐。击败低血量永琳并走出回廊后，辉夜才会登场，同时切换本次提供的终末音乐。

- 使用提供的辉夜 24 格原画裁剪透明素材，保留黑长发、和服及五件难题宝物，与其他东方 Boss 统一角色尺度。
- 按永夜抄六面 B 的顺序展开龙颈玉、佛石钵、火鼠衣、燕子安贝、蓬莱枝，最后连续挑战五段「永夜归返」。四难度分别有 **10 / 11 / 12 / 13 阶段**；Lunatic 需要自选植物。
- 塔防特化加入五色落珠、可击破的石钵护阵、火衣灼地、子安贝生命线和玉枝连锁打击。世界仍会切换水、岩浆和屋顶格，危险格提前预警，传送带会补给对应底座。
- **时间回溯**会记录植物与普通僵尸。倒计时结束，死去的记录单位复活，位置与生命恢复，期间新种植物和新出现小怪消失；大招消耗、奖励、Boss 血量、阶段与关卡进度不回退。击碎子安贝可以取消它触发的生命线回溯。
- Normal 追加「停长的月下花圃」，Hard 追加「一瞬千年的收割」，Lunatic 追加「万象倒映时庭」。这些原创技能影响植物行动、格子和单位生死，不只增加子弹数量。
- **3-23 加入飞艇玉兔**：固定事件、道中和终末增援均可出现，保留最多两艘、第三列返航、沿路投下防御玉兔、能被地面植物击中的规则。
- **东方关卡移除机甲僵尸与飞轮僵尸**，包括随机池和技能召唤来源，替换为投石车或铁门僵尸；其他世界保留原配置。

原作符卡编号与难度分支已核对。按本次要求，6B 道中刻意沿用 6A 的永琳「壶中的天地」；原作 6B 的道中是「壶中的大银河」。回溯、宝物护阵和变换世界等为本作塔防改编，不作为原作已有机制描述。

验证涵盖：四难度完整阶段、道中击破门禁、道中/终末音乐、暂停/重试、真实回溯与奖励去重、植物/底座复活、飞艇状态恢复、宝物破解、伤害预警、东方难度/符卡回归，以及 1600×900 和 844×390 原生画面检查。
