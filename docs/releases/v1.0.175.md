# v1.0.175 传送带与东方终末平衡

传送带降低连续补牌量，东方完整终末增加招式、生命与持续敌群；道中继续保持弱化形态。

- **补牌节奏**：4-19 从 1.6–2.3 秒、4-20 从 1.4–2.0 秒，统一放慢到每 2.8–4.0 秒一张。满带暂停下一张的等待，不再用 1.4 秒短重试提前补牌。保留开场三张及第一张补牌，普通关原有 4.6–6.8 秒节奏不变。固定种子持续取牌的 60 秒测试（含开场种子）由 34／39 张降到 22 张。
- **东方终末生命**：完整终末角色的生命较 v1.0.174 增加约 34.5%，分段生命与当前阶段血条同步。不同角色道中与同角色预览道中的生命、原有招式、退场和音乐边界均保留；蓝转紫的后继也使用完整终末生命。
- **新增原创符卡**：33 个角色定义共新增 73 张可实际施放的原创卡；每个完整终末增加 2 个独立阶段，最短角色增加 3 个。新卡改变阵型、运动和道具：冰排错时解冻、银刃停走与折返、七曜双元素换相、五个人偶实际发射并牵引激光、三骚灵本体错拍接力、半灵交错剑痕、边界对门、秋姐妹的枫叶金穗、雏的厄偶旋环及萃香的地岩酒火等。全部标为原创，保留原作符卡身份与相对顺序。
- **预警与反制**：新增卡持续 6.5／7.5 秒；子弹先预警 1.15 秒，激光预警 1.25–1.35 秒，实际发波间隔最低 1.1 秒。保持可受伤、镜返、时停与阶段清理，不增加全局不可见攻击或长时间无敌。芙兰的末尾两张与辉夜、妹红的终结段保持连续，幽幽子的复活流程保留。
- **终末持续增援**：4-19、4-20、8-6 在完整 Boss 登场后 1.8 秒开始跨行增援，E/N 每批 2 只，H/L 每批 3 只。基础间隔随阶段从 6.4 秒缩至 4.4 秒，再应用原有难度节奏；每个入场敌人都检查 42 个敌方及待入场单位的上限。雏的每批都有毛玉与精灵，后期加入铁桶、砖块和武士盔融合；秋穰子与萃香加入更丰富的普通、护甲及融合僵尸。弱化道中仍使用单只增援与原有间隔。
